## 2. 论文定位与中心思想

### 2.1 一句话中心思想

**本文不是"YOLO11 改进版"，而是面向 127MP 超高清工业图像的一套"分辨率保持训练—预算约束两阶段推理—级联风险校准"一体化检测框架，在 ≤10s 部署约束下解决几十像素微小缺陷的尺度坍缩与高误报问题。**

### 2.2 核心问题定义（三个硬约束）

| 约束 | 数值 | 来源 |
|---|---|---|
| 图像分辨率 | 单张约 13000×9800 ≈ 1.27 亿像素（127MP） | 福州地铁接触网检测车全景成像 |
| 缺陷尺度 | 螺母缺失/松动、销钉缺口等仅占原图数十像素（20~60px） | 数据集统计 |
| 部署约束 | 车载端 + 地面端单张推理 ≤10s，Recall≥90%、Precision≥90% | 合同验收要求 |

### 2.3 核心矛盾（论文的"问题张力"）

```text
整图 resize 到 1024  →  20px 缺陷压成 ~1.6px，经 stride-8/16 下采样后退化为亚像素弱响应，不可学习
全图原生分辨率密集切片 →  约 180 个 tile（1024 无重叠），计算冗余大，超 10s 预算
```

量化证据：

| 缺陷原尺寸 | resize 1024 后 | P3 特征(÷8) | P4 特征(÷16) | 可学习性 |
|---|---:|---:|---:|---|
| 20 px | 1.6 px | 0.2 cell | 0.1 cell | 不可学习 |
| 40 px | 3.2 px | 0.4 cell | 0.2 cell | 勉强 |
| 60 px | 4.7 px | 0.6 cell | 0.3 cell | 弱 |

### 2.4 论文主张（Thesis Statement）

> 缺陷检不出的**首要原因不是检测器容量不足，而是整图 resize 造成的微小缺陷表征坍缩**。因此提出一个训练（原生分辨率 crop）、推理（ROI 两阶段 + tile 调度）、部署（级联复核 + 每类阈值校准）三者一致的方法框架，在 10s 预算内同时保住小缺陷可学习性与 Recall/Precision ≥90%。

这一主张把你已实现的所有模块（原生 crop、两阶段、级联、阈值校准、HN 闭环、多源预训练）统一成一条叙事，而非 7 个孤立技巧的堆砌。

### 2.5 论文定位（写给谁看）

| 定位 | 含义 |
|---|---|
| 不写 | "基于 YOLO11-EMA-SimAM 的地铁接触网缺陷检测"（会被归为增量组合） |
| 要写 | "面向 127MP 超高清地铁接触网图像的分辨率保持训练、预算约束推理与风险校准检测框架" |

## 3. 论文主线（叙事逻辑链）

四段式：**现象 → 归因 → 方法 → 验证**，每段都有对应代码与实验支撑。

### 段一：现象与问题定义（Problem）

- 陈述 127MP + 微小缺陷 + ≤10s + ≥90% 的工程约束；
- 给出像素尺寸分布表（§2.3），量化 resize 的尺度坍缩；
- 说明接触网缺陷是"规则结构中的局部异常"，与通用小目标不同。

### 段二：归因（Attribution，论文的灵魂）

- **核心实验**：全图 resize 训练 vs 原生 crop 训练，证明 resize 导致小缺陷 Recall 崩、crop 恢复 Recall；
- 这一步直接区别于 SAHI（SAHI 只做推理切片，本文强调**训练—推理像素尺度一致性**）；
- 引用 analysis 文档结论：C2 全量训练收益极低 → 骨干没学到有效领域特征 → 问题在输入尺度而非模型容量。

### 段三：方法（Method，三块递进）

1. **训练侧 RPT**：原生分辨率 crop + 去中心化采样 + 边界样本 + 难负样本；
2. **推理侧 Two-Stage ROI + 预算约束**：先 ROI 定位结构、再对高风险 tile 精检，控制 tile 数；
3. **部署侧 Cascade + 每类阈值校准**：级联二分类器降 FP，per-class 阈值定车载高召回 / 地面高精度双工作点。

### 段四：验证（Validation）

- 强 baseline 对比（§6）+ 逐模块消融（§7）+ 逐类误差分析 + 端到端 127MP 时延。

## 4. 创新点体系

**3 主 + 1 辅**，全部锚定已实现代码。状态标注：✅ 已实现可测 / 🟡 部分实现需补强 / ⬜ 未实现需开发。

### 4.1 创新点一（第一主创新）：PSA-RPT 分辨率保持训练协议

- **英文名**：Pixel-Scale Aligned Resolution-Preserving Training
- **状态**：✅ 核心已实现，🟡 需补 PSDD 尺度分布指标
- **核心思想**：不是"切图训练"，而是让训练样本的缺陷像素尺度、位置分布、上下文范围与推理阶段保持一致，包含三层：
  1. 像素尺度守恒（不被整图 resize 压缩）；
  2. 训练—推理一致（crop 尺寸/重叠/边界截断/负样本类型与推理 tile 一致）；
  3. 可学习性约束（微小缺陷在输入图与浅层特征图上仍有足够像素表达）。
- **已实现代码**：[scripts/generate_native_crops.py](../scripts/generate_native_crops.py)（原生 1024/1280 crop、正样本绕缺陷 bbox、去中心化采样、负样本来自视觉相似区域、按 source 划分）
- **建议新增指标 PSDD**：`PSDD = Wasserstein(S_train ∥ S_infer)`，衡量训练 crop 与推理 tile 中缺陷 bbox 像素尺寸分布的偏差。**这是区别于 SAHI 的关键卖点。**
- **区别于已有工作**：
  - SAHI 是"推理时切片 + 全图/切片微调"，未强调训练—推理尺度分布对齐；
  - ASAHI 控制切片数量降冗余，未提 PSDD 与去中心化采样；
  - 本文强调"训练分布 = 推理分布"的**可度量对齐**。

### 4.2 创新点二（第二主创新）：Two-Stage ROI + 预算约束推理

- **英文名**：Budget-Constrained Two-Stage ROI Inference（BCAT 的落地版）
- **状态**：🟡 ROI 两阶段 + 固定切片 ✅，`BudgetTileScheduler`（动态 tile 调度）⬜ 未实现
- **核心思想**：
  1. Stage 1：YOLO11n 在 1/8 下采样图上定位结构 ROI，快速筛掉大量背景；
  2. Stage 2：缺陷检测器只对 ROI 相交的原生分辨率 tile 精检；
  3. 预算约束：在 ≤10s / ≤K tiles 内优先处理高风险 tile（`tile_score = α·roi_score + β·structure_density + γ·boundary_risk − λ·compute_cost`）。
- **已实现代码**：
  - [subway_defect/pipeline/two_stage.py](../subway_defect/pipeline/two_stage.py)（ROI → defect 两阶段）
  - [subway_defect/pipeline/slicer.py](../subway_defect/pipeline/slicer.py)（SmartSlicer）
- **需补**：`BudgetTileScheduler`（[slicer.py](../subway_defect/pipeline/slicer.py) 的 `candidate_tiles` + 排序选择）。若时间不够，论文诚实写为"ROI 两阶段切片"，不写动态调度器。

### 4.3 创新点三（第三主创新）：Cascade + 车载/地面双模式风险校准

- **英文名**：Cascade Verification & Edge-Ground Risk Calibration（EGRC）
- **状态**：🟡 级联 ✅、per-class 阈值 ✅；onboard/ground 分离阈值文件 ⬜
- **核心思想**：
  1. **级联复核**：YOLO 检出后，对每个候选框 crop（1.75× 上下文）跑 per-class MobileNetV3 二分类器，判"正常"则拒收；VHBNM/VHBNL 用层级 L1（正常/缺陷）→L2（缺失/松动）两级；
  2. **双模式工作点**：车载端低阈值高召回（宁可多报不漏），地面端高阈值高精度（复核降误报），每类阈值独立搜索。
- **已实现代码**：
  - [subway_defect/pipeline/cascade.py](../subway_defect/pipeline/cascade.py)（级联分类器 + 层级 L1/L2）
  - [subway_defect/classifier/](../subway_defect/classifier/)（MobileNetV3 分类器训练/推理）
  - [scripts/calibrate_thresholds.py](../scripts/calibrate_thresholds.py)（per-class 阈值）
- **需补**：`thresholds_onboard.json` / `thresholds_ground.json` 双文件 + FastAPI 按 mode 加载。

### 4.4 辅助创新点：MDCP 多源课程预训练 + HNL 难负样本闭环

- **英文名**：Multi-source Defect Curriculum Pretraining + Hard-Negative Loop
- **状态**：✅ 已实现（HNL 效果待补强）
- **核心思想**：
  1. 课程式迁移：COCO（通用）→ TT100K（小目标）→ DeepPCB/NEU/GC10（工业缺陷纹理）→ 绝缘子/电力（近域）→ 自制接触网（类别精调），证明"课程式 > 混数据"；
  2. 难负样本闭环：训练 → 全图推理 → 收集误检 → 人工确认 → 加入再训练 → 阈值校准。
- **已实现代码**：
  - [scripts/multi_source_dataset_builder.py](../scripts/multi_source_dataset_builder.py)
  - [scripts/collect_hard_negatives.py](../scripts/collect_hard_negatives.py)
  - [scripts/generate_synthetic_defects.py](../scripts/generate_synthetic_defects.py) / [generate_defect_copy_paste.py](../scripts/generate_defect_copy_paste.py)
  - [scripts/generate_scene_augmentations.py](../scripts/generate_scene_augmentations.py)

### 5.1 模型架构（YOLO11s-v2）

来源：[subway_defect/models/yolo11s-v2.yaml](../subway_defect/models/yolo11s-v2.yaml)

| 属性 | 值 |
|---|---|
| 参数量 | 9.98M |
| 计算量 | 33.3 GFLOPs |
| 层数 | 249 |
| 类别 | nc=18（运行时由数据集覆盖，当前 16 类） |
| 尺度 | s:[0.50, 0.50, 1024] |

**骨干（Backbone）**：

| 层 | 模块 | 作用 |
|---|---|---|
| P1/P2 | Conv | 下采样 |
| P3 | C3k2 + **LSK** | 大选择核，自适应感受野（适应不同螺栓尺寸） |
| P4 | C3k2 | 中尺度 |
| P5 | SPPF + C2PSA | 多尺度池化 + 原生空间注意力 |
| 全局 | **DCN**（可变形卷积） | 增强小目标形变适应 |

**颈部 + 检测头（Head，P2 四尺度）**：

| 分支 | 注意力 | 定位 |
|---|---|---|
| P2（4×） | **SimAM**（参数自由能量注意力） | 微小目标 |
| P3（8×） | **EMA**（空间+通道多尺度） | 小目标 |
| P4（16×） | **CoordAtt**（坐标注意力，方向敏感） | 中目标，"松动"类方向特征 |
| P5（32×） | **SimAM** | 大目标 |

**多任务辅助头（AuxHead）**：backbone P3 后接 9 类部件类型分类（VHB/SVHB/SVHTN/CBH/CBV/RHTBN/BSB/INSD/DRPS），loss_weight=0.1，dropout=0.2。

**损失**：Wise-IoU + FL_gamma=2.0 + class_weights（尾部类加权）。

### 9.2 摘要草稿（中文）

> 针对地铁接触网巡检中 1.27 亿像素级超高清图像的小缺陷检测问题，直接整图缩放会使螺母缺失/松动、销钉缺口等几十像素的微小缺陷坍缩为亚像素弱响应，难以被深度检测器学习；而全图原生分辨率密集切片又难以满足车载端与地面端单张 10 秒的部署约束。为此，本文提出一种分辨率保持训练与预算约束两阶段推理、级联风险校准一体化的检测框架。首先，设计像素尺度对齐的分辨率保持训练协议（PSA-RPT），在原生分辨率下构造正样本、难负样本与边界样本，使训练样本的缺陷像素尺度分布与推理阶段一致；其次，采用 ROI 两阶段推理，先定位结构区域、再对高风险 tile 精检，在有限推理预算内优先处理高风险区域；最后，通过级联二分类复核与逐类阈值校准，在不同部署模式下平衡召回率与精确率。实验在源分组零泄漏的冻结测试集上，从像素尺度分布、检测精度、误报率、漏检率与单图推理时延等方面验证所提方法的有效性。

## 10. 风险与应对

| 风险 | 审稿人质疑 | 应对 |
|---|---|---|
| 被归为 SAHI 变体 | "就是切片" | 强调训练—推理尺度一致性 + PSDD + resize-vs-crop 因果实验 |
| 被归为 YOLO 堆模块 | "注意力堆叠" | 模块降为消融细节，主线是框架一致性 |

| 私有数据不公开 | 无法复现 | 公开代码 + 公开数据集复现 + 脱敏样例 + 详尽协议 |
| 4 类零样本 | 16 类只训 12 类 | 明确写"12 类有效监督 + 4 类待补"，不夸大覆盖 |
| TTA/HN 负结果 | 问为何不提 | 主动报告作负结果贡献，反证方向注意力必要性 |
