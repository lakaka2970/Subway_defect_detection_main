# 当前模型性能分析、问题诊断与改进建议
## ——结合 YOLO11m / YOLO11m-P2 实验、Label 分布与 Transformer 二级复核方案 C

> **分析对象**：地铁接触网缺陷检测项目  
> **当前主模型**：YOLO11m-EMA-SimAM（三尺度 P3/P4/P5）  
> **对照模型**：YOLO11m-P2-EMA-SimAM（四尺度 P2/P3/P4/P5）  
> **重点方案**：方案 C —— YOLO 主检测器 + Tiny Transformer 二级状态复核器  
> **核心约束**：127MP 原始图像、单张推理 ≤10 秒、Precision ≥90%、Recall ≥90%、车载端离线部署、模型加载 ≤1 秒

---

## 0. 结论先行

当前项目的瓶颈已经不再是单纯的“小目标看不见”，而是：

1. **正常结构与缺陷结构高度相似，导致误报多、Precision 低**；
2. **松动类、缺失类属于细粒度状态识别问题，普通检测头难以稳定区分**；
3. **P2 四尺度模型虽然增加了高分辨率细节，但没有提升整体性能，反而放大了背景噪声和误报**；
4. **SVHBNM 样本最多但 AP 最低，说明问题不是简单样本数量不足，而是类别定义、视觉可分性、标注一致性、背景混淆共同造成的**；
5. **当前最适合引入 Transformer 的方式不是替换 YOLO 主模型，而是作为二级复核分类器，专门处理 VHBNL / SVHBNL / SVHBNM / CBVPM 等难类候选。**

因此推荐的下一步主线是：

```text
YOLO11m-EMA-SimAM 三尺度模型作为主检测器
→ 修复 Stage 1 到 Stage 2 的权重继承
→ 加入 hard negative mining
→ 生成难类候选 crop
→ 训练 Tiny Transformer 二级分类器
→ 在推理时只对低置信难类候选做复核
→ 每类阈值校准
```

## 1. 项目约束与设计边界

本项目不是普通离线检测实验，而是强工程约束下的工业质检系统。

| 约束项 | 要求 | 对模型设计的影响 |
|---|---:|---|
| 输入规模 | 1.27 亿像素，约 13000×9800 | 不能整图直接大模型推理，必须 ROI / slicing |
| 单张推理耗时 | ≤10 秒 | 主模型不能无限加大 |
| Recall | ≥90% | 漏检必须尽量少 |
| Precision | ≥90% | 误报也必须严格控制 |
| 车载端 | 单 RTX 4090，离线运行 | 模型需可 TensorRT / FP16 加速 |
| 模型加载 | ≤1 秒 | 不适合过大 Transformer 主干 |
| 当前类别 | 7 类有标注，未来扩展到更多类 | 训练流程需可扩展 |

已有系统设计采用两级级联：先做 ROI 提案，再对 ROI 区域做 1024 切片检测，理论总耗时约 5.2 秒，说明当前 YOLO 主检测器仍有部署可行性空间，但不能随意引入过重结构。

## 2. 当前三尺度 YOLO11m-EMA-SimAM 性能分析

### 2.1 模型结构

当前主模型为 **YOLO11m-EMA-SimAM**，结构为三尺度检测：

```text
P3 / 8  → EMA
P4 / 16 → SimAM
P5 / 32 → ECA
```

模型规模：

| 指标 | 数值 |
|---|---:|
| 参数量 | 20,691,816，约 20.7M |
| GFLOPs | 75.6 |
| 检测尺度 | P3 / P4 / P5 |
| Stage 1-2 输入 | 1024 |
| Stage 3-4 输入 | 1280 |

该模型的优点是结构相对稳定，计算量可接受，且已经通过统一四阶段训练显著超过旧版 C1/C2/C3 流程。

---

### 2.2 四阶段训练结果

| 阶段 | 数据 | 目标 | 最佳 mAP50 | 最佳 mAP50-95 | 主要结论 |
|---|---|---|---:|---:|---|
| Stage 1 | DeepPCB + NEU-DET + GC10-DET | generic_defect 公开缺陷预训练 | 0.838 | 0.597 | 公开缺陷预训练有效 |
| Stage 2 | subway_crops | 7 类领域适配 | 0.462 | 0.325 | 有效但未继承 Stage 1，潜力未释放 |
| Stage 3 | subway_crops | 1280 主训练 | 0.503 | 0.353 | 当前主要收益阶段 |
| Stage 4 | subway_crops | 低 LR 短微调 | 0.499 | 0.355 | 收益很小，需修正 warmup bias |

最终三尺度模型逐类表现：

| 类别 | Precision | Recall | mAP50 | mAP50-95 | 判断 |
|---|---:|---:|---:|---:|---|
| VHBNM | 0.616 | 0.742 | 0.720 | 0.532 | 表现较好 |
| VHBNL | 0.367 | 0.633 | 0.386 | 0.259 | 松动类难识别 |
| SVHBNM | 0.223 | 0.458 | 0.251 | 0.197 | 最困难类别 |
| SVHBNL | 0.407 | 0.368 | 0.366 | 0.236 | 样本少 + 状态难 |
| SVHTNL | 0.581 | 0.717 | 0.584 | 0.522 | 表现中等偏好 |
| CBHPM | 0.576 | 0.756 | 0.767 | 0.484 | 最强类别之一 |
| CBVPM | 0.307 | 0.473 | 0.404 | 0.254 | 视角和结构依赖强 |
| **All** | **0.439** | **0.593** | **0.497** | **0.355** | 尚未接近验收指标 |

### 2.3 当前性能结论

1. **总体 mAP 已明显优于旧流程，但 Precision/Recall 仍远低于项目验收目标。**
2. **高 AP 类别具有形态稳定、缺陷明显、背景一致的特点**，如 VHBNM 和 CBHPM。
3. **低 AP 类别不是统一原因**：
   - SVHBNM：数量多但 AP 低，说明是视觉混淆和类别可分性问题；
   - SVHBNL：样本少且是松动状态识别；
   - VHBNL：松动与正常/缺失边界模糊；
   - CBVPM：视角依赖、缺口可见性弱。
4. **当前主模型已经能发现一部分缺陷，但还不能有效判断“相似正常结构是否真缺陷”。**

## 3. Label 分布带来的进一步诊断

### 3.1 Stage 1 公开缺陷标签

Stage 1 公开缺陷数据共有：

```text
generic_defect: 13,817 instances
```

其特点：

- 单类 generic_defect，不存在类别不平衡；
- 目标位置较分散；
- 目标尺度集中在小目标和局部异常区域；
- 适合学习“工业异常纹理”和“局部缺陷定位”。

但当前训练中出现严重问题：

```text
Stage 2 没有继承 Stage 1 best.pt，而是重新从 weights/yolo11m.pt 初始化。
```

这意味着 Stage 1 公开缺陷预训练的收益没有真正传递到接触网 7 类训练。

---

### 3.2 Stage 2-4 接触网 labels 分布

Stage 2-4 使用相同的 `subway_crops` label 分布：

| 类别 | 实例数 | 占比 | 当前三尺度 mAP50 | 问题判断 |
|---|---:|---:|---:|---|
| VHBNM | 987 | 18.86% | 0.720 | 数量足、形态明显 |
| VHBNL | 673 | 12.86% | 0.386 | 松动类，状态难判 |
| SVHBNM | 1,197 | 22.87% | 0.251 | 数量最多但效果最差 |
| SVHBNL | 362 | 6.92% | 0.366 | 最少类 + 松动状态 |
| SVHTNL | 773 | 14.77% | 0.584 | 表现中等偏好 |
| CBHPM | 701 | 13.39% | 0.767 | 特征稳定，效果最好 |
| CBVPM | 541 | 10.34% | 0.404 | 垂直销钉缺口视角受限 |
| **合计** | **5,234** | **100%** | **0.497 All** | — |

### 3.3 Label 分布揭示的核心问题

#### 3.3.1 SVHBNM 不是样本数量问题

SVHBNM 有 1,197 个训练实例，是数量最多的类别，但当前三尺度 mAP50 仅 0.251。  
这说明它的主要问题不是“样本少”，而是：

```text
1. 缺失状态视觉差异弱；
2. 正常槽钢底座、螺母边缘、阴影、反光与缺陷高度相似；
3. 标注框可能存在尺度或位置不一致；
4. 类别定义可能与其他螺母缺失/松动类有边界模糊；
5. 检测模型只能看到“局部像缺陷”，但缺少“正常结构对照”的判断能力。
```

#### 3.3.2 SVHBNL 是明确的小样本 + 细粒度问题

SVHBNL 只有 362 个实例，是最少类，同时属于松动状态识别。  
它需要：

- 补充样本；
- 类别重采样；
- 正常螺母难负样本；
- 二级状态分类器。

#### 3.3.3 松动类本质上不是普通检测问题

VHBNL 和 SVHBNL 的“松动”不是一个独立明显物体，而是结构状态异常：

```text
normal → loose → missing
```

它更像局部状态分类，而不是单纯框检测。  
因此强行用 YOLO 一步完成定位 + 状态判断，难度较高。

#### 3.3.4 位置分布存在结构性聚集

Labels 图显示缺陷位置集中在若干区域。这既说明接触网结构在 crop 中有位置先验，也说明模型可能学习到位置偏置。  
因此后续训练需要位置去偏置 crop，让缺陷出现在中心、边缘、左上、右上等不同区域，避免模型过度依赖固定空间位置。

| SVHBNL | 19 | 19 | 0.241 | 0.316 | 0.214 | 0.151 |
| SVHTNL | 46 | 46 | 0.586 | 0.804 | 0.681 | 0.590 |
| CBHPM | 45 | 45 | 0.392 | 0.578 | 0.502 | 0.298 |

模型规模：

```text
YOLO11m-P2-EMA-SimAM:

```

### 4.2 与三尺度模型对比

| 指标 | 三尺度 YOLO11m | P2 四尺度 YOLO11m-P2 | 变化 |
|---|---:|---:|---:|
| Precision | 0.439 | 0.372 | -0.067 |
| Recall | 0.593 | 0.604 | +0.011 |
| mAP50 | 0.497 | 0.430 | -0.067 |
| mAP50-95 | 0.355 | 0.310 | -0.045 |
| GFLOPs | 75.6 | 95.5 | +19.9 |

### 4.3 P2 结果说明了什么

#### 4.3.1 P2 增加了召回倾向，但降低了精度

P2 的 Recall 从 0.593 小幅提升到 0.604，但 Precision 从 0.439 下降到 0.372。  
这说明 P2 分支确实让模型更容易产生候选框，但也让大量正常纹理被误报为缺陷。

#### 4.3.2 P2 没有解决核心难类

| 类别 | 三尺度 mAP50 | P2 mAP50 | 结论 |
|---|---:|---:|---|
| SVHBNM | 0.251 | 0.197 | 更差 |
| SVHBNL | 0.366 | 0.214 | 更差 |
| CBVPM | 0.404 | 0.320 | 更差 |
| VHBNL | 0.386 | 0.400 | 略升但 Precision 仍低 |
| SVHTNL | 0.584 | 0.681 | 明显提升 |

P2 对 SVHTNL 有帮助，但对 SVHBNM、SVHBNL、CBVPM 反而不利。  
这说明这些类别的问题不是单纯“空间分辨率不足”，而是“细粒度状态识别 + 正常结构混淆”。

#### 4.3.3 P2 破坏了部分中等目标学习

CBHPM 从三尺度 mAP50 0.767 降到 P2 的 0.502。  
CBHPM 并不是最小目标，理论上不应依赖 P2。该类大幅下降说明：

```text
1. 新增 P2 分支改变了检测尺度分工；
2. 高分辨率分支吸收了过多梯度；
3. P3/P4 中尺度分支学习受到干扰；
4. NMS / 分类排序被更多低质量候选影响；
5. P2 没有与当前数据分布和训练流程适配。
```

### 4.4 对 P2 的结论

当前 P2 版本不应作为主线模型。

更合理的定位是：

```text
1. 作为消融实验；
2. 作为地面端辅助模型；
3. 或者改成 P2-Lite；
4. 或仅用于低置信小目标候选复检。
```

当前主线仍应回到三尺度 YOLO11m-EMA-SimAM。

## 5. 当前核心问题分层诊断

### 5.1 训练流程问题

#### 问题 1：Stage 2 未继承 Stage 1

这是当前最严重工程问题。

```text
Stage 1 学到 generic defect
但 Stage 2 重新从 COCO 权重开始
导致公开缺陷预训练收益没有进入目标域训练
```

改进：

```text
Stage 2 pretrained 必须指向 Stage 1 / Stage 1B best.pt
nc=1 → nc=7 时加载 backbone + neck + attention
重新初始化 Detect 分类输出层
```

---

#### 问题 2：Stage 4 warmup bias 学习率异常

之前解析训练曲线时发现 Stage 4 虽然设置 `lr0=3e-5`，但 bias 参数组前两轮学习率异常高。  
这会破坏“极低学习率真实分布微调”的目的。

改进：

```yaml
warmup_epochs: 0
warmup_bias_lr: 0.00001
```

---

#### 问题 3：Stage 3 后半过拟合

Stage 3 最佳点在 40~57 epoch，最终 97 epoch 早停时指标下降。  
下一轮应缩短 Stage 3。

推荐：

```yaml
epochs: 80
patience: 25
close_mosaic: 35
```

---

### 5.2 数据问题

#### 问题 1：难负样本不足

当前正样本 labels 分布比较清楚，但难负样本没有被系统建模。  
Precision 低说明模型把很多正常结构误报为缺陷。

必须加入：

```text
正常螺母
正常槽钢底座
正常销钉
正常开口销
金属反光
阴影边缘
运动模糊
切片边界
完整但姿态接近松动的结构
```

#### 问题 2：SVHBNM 需标注审计

SVHBNM 样本最多但 AP 最低，应优先抽样审计，而不是盲目补数据。

检查项目：

```text
1. 框是否过大；
2. 框是否偏移；
3. 是否混入正常结构；
4. 是否与 VHBNM / SVHBNL 定义混淆；
5. 是否存在同一缺陷不同标注尺度；
6. 是否有漏标导致模型把真实缺陷当背景学习。
```

#### 问题 3：松动类定义需要结构化

松动类应建立明确标注标准：

```text
normal：螺母位置正常，无遮挡、无明显偏移
loose：螺母存在但相对基座/螺纹/垫片位置异常
missing：目标结构应有螺母但不可见或明显缺失
uncertain：无法可靠判断，不进入训练或单独标注
```

---

### 5.3 模型问题

#### 问题 1：YOLO 检测头不擅长细粒度状态复核

YOLO 擅长定位“目标在哪里”，但对以下问题不够稳定：

```text
正常螺母 vs 松动螺母
正常底座 vs 缺失螺母
正常销钉 vs 销钉缺口
反光边缘 vs 缺陷边缘
```

这些问题更适合局部 crop 分类。

#### 问题 2：P2 分支带来更多低质量局部响应

P2 让模型看到更多细节，但当前数据里正常金属结构细节也很多。  
因此 P2 提高 Recall 的同时放大了 FP，不符合当前最迫切的 Precision 提升需求。

## 6. 为什么推荐方案 C：Tiny Transformer 二级复核

### 6.1 方案 C 的本质

方案 C 不是用 Transformer 替代 YOLO，而是建立二级判断器：

```text
第一级：YOLO11m-EMA-SimAM
负责快速定位候选缺陷框

第二级：Tiny Transformer / MobileViT / Swin-Tiny 分类器
负责判断候选区域是真缺陷还是相似正常结构
```

它解决的是：

```text
YOLO 能找到疑似异常
但 YOLO 不擅长判断细粒度状态
```

### 6.2 为什么不建议直接换 Transformer 主模型

直接换 Transformer 主检测器存在风险：

| 风险 | 原因 |
|---|---|
| 推理速度风险 | 127MP 图像需要大量 ROI / slice 推理 |
| TensorRT 风险 | Transformer 算子部署复杂度更高 |
| 数据量风险 | 当前自制数据仍偏少 |
| Precision 风险 | 没有 hard negative 时，Transformer 也可能学习背景纹理 |
| 已有证据 | P2 增强细节后 Precision 下降，说明更多细节不等于更好判断 |

因此 Transformer 最适合做二级复核，而不是主检测器替换。

## 7. 方案 C 的系统设计

### 7.1 总体推理流程

```text
127MP 原图
→ ROI 提案器
→ ROI 切片
→ YOLO11m-EMA-SimAM 三尺度检测
→ 按类别和置信度筛选候选框
→ 难类候选进入 Tiny Transformer 二级复核
→ 融合 YOLO 分数与分类器分数
→ 每类阈值校准
→ 输出最终缺陷框
```

### 7.2 哪些候选进入二级复核

不建议所有框都复核，只复核难类和低置信候选。

推荐规则：

| 类别 | 进入复核条件 | 原因 |
|---|---|---|
| SVHBNM | conf 0.10–0.80 | 样本多但误报严重 |
| SVHBNL | conf 0.10–0.85 | 少样本 + 松动状态 |
| VHBNL | conf 0.10–0.80 | 松动状态难 |
| CBVPM | conf 0.10–0.75 | 视角和结构混淆 |
| VHBNM | conf 0.15–0.55 | 高置信通常较可靠 |
| CBHPM | conf 0.15–0.50 | 原本强类，仅复核低置信 |
| SVHTNL | conf 0.15–0.60 | P2 中表现好，但仍需控制误报 |

不进入复核的情况：

```text
1. 高置信且历史表现稳定的类别；
2. 非难类且 conf 很高；
3. 框尺寸明显异常的候选，可直接规则过滤；
4. ROI 提案器未覆盖或结构位置不合理的候选。
```

## 8. 二级 Transformer 分类器的数据构建

### 8.1 数据来源

二级分类器的数据不应只来自原始标注框，还应来自 YOLO 的真实错误。

数据来源包括：

```text
1. YOLO TP crop：模型正确检测的缺陷；
2. YOLO FP crop：模型误报的正常结构；
3. YOLO FN crop：漏检缺陷位置；
4. 原始标注 crop：人工标注缺陷；
5. 正常结构 crop：从无缺陷区域主动采样；
6. 低置信候选 crop：最接近决策边界的样本。
```

### 8.2 推荐类别体系

不要直接用 7 类做二级分类。建议按结构状态设计类别。

#### 方案 C1：四类状态分类，推荐第一版

```text
normal
missing_nut
loose_nut
pin_gap
```

映射关系：

| YOLO 类别 | 二级分类目标 |
|---|---|
| VHBNM | missing_nut |
| SVHBNM | missing_nut |
| VHBNL | loose_nut |
| SVHBNL | loose_nut |
| SVHTNL | loose_nut 或 separate_top_nut_loose |
| CBHPM | pin_gap |
| CBVPM | pin_gap |
| 正常螺母/销钉/底座 | normal |

优点：

- 减少类别数；
- 增强正负对比；
- 适合小数据；
- 专注判断状态，而不是重复做 YOLO 的 7 类分类。

#### 方案 C2：结构位置 + 状态双头分类，第二版可尝试

```text
head 1: structure_type
  vertical_hanger_base
  single_vertical_channel_base
  top_nut
  cantilever_pin

head 2: state
  normal
  missing
  loose
  pin_gap
```

最终组合得到具体类别。  
这更符合接触网结构逻辑，但实现更复杂。

---

### 8.3 Crop 生成规则

对于每个 YOLO 候选框，生成二级分类输入：

```text
原框 bbox
→ 扩展 1.5x / 2.0x / 3.0x
→ 裁剪局部结构上下文
→ resize 到 224×224 或 256×256
→ 输入 Transformer 分类器
```

建议保留多种 crop 比例：

| crop 比例 | 作用 |
|---|---|
| 1.2x | 看缺陷细节 |
| 2.0x | 看螺母/销钉与底座关系 |
| 3.0x | 看结构上下文 |

如果只裁原框，分类器可能缺少判断“该位置是否应该有螺母”的上下文。

---

### 8.4 正负样本比例

二级分类器最重要的是 normal hard negative。

推荐比例：

```text
normal : defect = 1.5 : 1 到 2 : 1
```

难类内部建议：

| 类型 | 采样策略 |
|---|---|
| normal | 强过采样，尤其是 YOLO 误报区域 |
| missing_nut | 保持正常采样 |
| loose_nut | 过采样 1.5–2.0 倍 |
| pin_gap | 过采样 1.2–1.5 倍 |
| uncertain | 不用于训练，单独存档 |

## 9. 二级 Transformer 模型选择

### 9.1 候选模型

| 模型 | 优点 | 风险 | 推荐程度 |
|---|---|---|---|
| MobileViT-XS | 轻量，适合部署 | 表达能力略弱 | 高 |
| MobileViT-S | 速度与精度均衡 | 略重 | 高 |
| Swin-Tiny | 局部窗口注意力强，适合结构纹理 | 计算量较高 | 中高 |
| EfficientFormer-L1 | 推理友好 | 工程集成需验证 | 中 |
| ViT-Small | 简单直接 | 数据量要求高 | 中低 |
| ConvNeXt-Tiny | 非 Transformer，但强 baseline | 不能作为 Transformer 亮点 | 高，作为对照 |

### 9.2 第一版推荐

第一版建议使用：

```text
MobileViT-S 或 Swin-Tiny
输入 224×224
类别数 4：normal / missing_nut / loose_nut / pin_gap
```

如果车载端时延紧张：

```text
MobileViT-XS
```

如果只做地面端：

```text
Swin-Tiny
```

### 9.3 性能目标

二级分类器不需要单独达到极高 mAP，它的目标是降低误报。

建议目标：

| 指标 | 目标 |
|---|---:|
| normal recall | ≥95% |
| defect recall | ≥90% |
| loose_nut F1 | ≥75% |
| missing_nut F1 | ≥80% |
| pin_gap F1 | ≥80% |
| 单 crop FP16 推理 | ≤2 ms |
| 每张 127MP 触发复核数量 | ≤100 个 |
| 二级复核总耗时 | ≤200 ms |

## 10. 二级分类器训练方案

### 10.1 数据划分

必须按源图分组划分，避免同源泄漏：

```text
train: 70%
val: 15%
test: 15%
```

不能将同一 127MP 源图或 5120 tile 的不同 crop 分到不同集合。

---

### 10.2 训练配置

```yaml
model: mobilevit_s 或 swin_tiny
input_size: 224
num_classes: 4

epochs: 80
batch_size: 64
optimizer: AdamW
lr: 0.0003
weight_decay: 0.05
scheduler: cosine
warmup_epochs: 5

augment:
  random_resized_crop: scale [0.75, 1.0]
  color_jitter: mild
  gaussian_blur: low probability
  random_rotation: ±3 degrees
  horizontal_flip: false 或按结构类别控制
  vertical_flip: false
  cutmix: false
  mixup: false

loss:
  cross_entropy 或 focal_loss
  class_weight:
    normal: 1.0
    missing_nut: 1.2
    loose_nut: 1.8
    pin_gap: 1.5
```

### 10.3 为什么不建议强增强

松动类依赖几何状态，强旋转、翻转、透视变换可能改变真实结构语义。  
因此增强应主要模拟：

```text
亮度变化
轻微模糊
轻微噪声
轻微位移
轻微尺度变化
```

不建议：

```text
大角度旋转
随机垂直翻转
强 cutmix / mixup
大面积 erase
```

## 11. YOLO 与二级分类器的分数融合

### 11.1 基础融合公式

设：

```text
s_yolo = YOLO 检测置信度
s_cls  = 二级分类器对目标状态的概率
```

推荐融合：

```text
s_final = sqrt(s_yolo * s_cls)
```

或：

```text
s_final = 0.6 * s_yolo + 0.4 * s_cls
```

第一版推荐使用加权平均，便于调参。

---

### 11.2 类别修正逻辑

二级分类器不仅过滤误报，还可以修正类别。

示例：

```text
YOLO 预测 SVHBNM
二级分类器输出 normal=0.92
→ 删除该框

YOLO 预测 VHBNL
二级分类器输出 missing_nut=0.81
→ 类别从 VHBNL 修正为 VHBNM 或保留为 missing_nut group 后再映射

YOLO 预测 CBVPM
二级分类器输出 pin_gap=0.88
→ 保留并提升置信度
```

### 11.3 建议第一版只做过滤，不做类别改写

为避免引入新错误，第一版推荐：

```text
如果 classifier 判断 normal 高，则删除；
如果 classifier 判断对应 defect 高，则保留；
暂不做类别改写。
```

第二版再尝试类别修正。

## 12. 与 Hard Negative Mining 的结合

二级 Transformer 的效果强依赖 hard negative。

### 12.1 Hard negative 收集流程

```text
1. 用当前 YOLO 三尺度模型跑 train / val / 未标注正常图；
2. 收集 conf 0.10–0.80 的候选框；
3. 人工确认其中的 FP；
4. 按结构类别标为 normal；
5. 加入二级分类训练集；
6. 训练二级分类器；
7. 用二级分类器过滤 YOLO 输出；
8. 观察 Precision 是否提升；
9. 将仍然误判的 FP 加入下一轮 hard negative。
```

### 12.2 最有价值的 hard negative

| 针对类别 | Hard negative |
|---|---|
| SVHBNM | 正常槽钢底座、正常小螺母、螺母边缘阴影 |
| SVHBNL | 正常但姿态变化的螺母、轻微模糊螺母 |
| VHBNL | 正常垂直悬吊底座螺母、反光螺母 |
| CBVPM | 完整垂直销钉、销钉阴影、边缘高光 |
| CBHPM | 完整横向销钉、结构孔洞边缘 |
| SVHTNL | 正常上方螺母、线夹边缘 |

## 13. 部署时延评估

### 13.1 二级复核不会破坏 10 秒约束的前提

二级模型只处理少量候选，不对所有 slice 全图运行。假设：

```text
每张 127MP 图像进入二级复核候选数：50–100
MobileViT-S FP16 单 crop：约 1–2 ms
总二级复核耗时：50–200 ms
```

在当前管道约 5.2 秒基础上，仍在 10 秒以内。

### 13.2 必须设置触发上限

防止异常图像产生过多候选：

```text
每张图最多复核 100 个候选
每类最多复核 30 个候选
优先复核 conf 接近阈值的候选
高置信稳定类直接通过
低置信明显噪声直接丢弃
```

## 17. 最终建议

当前模型已经证明多源训练和原生 crop 是有效的，但系统仍处于“能检出部分缺陷，但误报多、难类不稳”的阶段。

下一步的关键不是盲目加大主模型，也不是直接换成 Transformer，而是：

```text
用 YOLO 保持快速定位能力；
用 hard negative 修正误报；
用 Tiny Transformer 复核细粒度状态；
用每类阈值校准满足工程指标。
```

最终推荐路线：

```text
1. 修复三尺度 YOLO 训练流程；
2. 将三尺度 YOLO 作为主模型；
3. 放弃当前 P2 作为主线，仅保留消融或地面端辅助；
4. 建立 hard negative 数据闭环；
5. 训练 MobileViT-S / Swin-Tiny 二级状态分类器；
6. 将二级分类器只用于 SVHBNM / SVHBNL / VHBNL / CBVPM 等难类；
7. 通过阈值校准和复核过滤逐步提升 Precision；
8. 在满足 ≤10 秒约束后，再考虑更复杂的 Transformer neck 或地面端融合。
```

一句话总结：

> **本项目当前最需要的不是“更强的主检测器”，而是“更可靠的缺陷状态复核器”。Transformer 最适合以 Tiny 二级分类器的方式进入系统，用来解决 YOLO 难以处理的正常/松动/缺失/缺口细粒度判别问题。**
