## 1. 执行摘要

### 1.1 一句话结论

本轮训练（7.27）首次使用 **yolo11s-v2 架构**（P2 四尺度检测头 + CoordAtt + LSK）在 **12 类缺陷**上进行完整 Stage 2→3→4→5 训练，**Stage 4 best mAP50=0.485**，Precision=0.442，Recall=0.537。相较 7.24 的 7 类 mAP50=0.622 有显著下降，但考虑到类别数增加 71%（7→12）、数据集缩小 81%（52K→12K），表现合理。

### 1.2 核心量化结果

| 指标 | Stage 2 best | Stage 3 best | Stage 4 best | Stage 5 best | 验收目标 |
|------|:-----------:|:-----------:|:-----------:|:-----------:|:-------:|
| mAP50 | 0.354 | 0.443 | **0.485** | 0.473 | — |
| mAP50-95 | 0.234 | 0.328 | **0.386** | 0.374 | — |
| Precision | 0.300 | 0.374 | 0.442 | 0.595* | ≥ 0.90 |
| Recall | 0.502 | 0.552 | 0.537 | 0.412* | ≥ 0.90 |

> *Stage 5 的 P/R 为 epoch 10 值，HNM 使 Precision 与 Recall 呈反向变化。

### 1.3 推荐权重

| 用途 | 权重文件 | 说明 |
|------|---------|------|
| **通用检测（推荐）** | `weights/stage4_best_finetune.pt` | mAP50 最高（0.485），P/R 最均衡 |
| 高 Precision 场景 | `weights/stage5_calibrated.pt` | P=0.595，但 R 降至 0.412 |

## 2. 模型架构

### 2.1 YOLO11s-v2 架构概览

本轮训练首次使用 v2 架构，相较 v1（YOLO11s-EMA-SimAM）的改进：

| 组件 | v1 | v2 | 改进理由 |
|------|-----|-----|---------|
| 检测尺度 | P3/P4/P5（3 尺度） | **P2/P3/P4/P5（4 尺度）** | 最小检测目标从 ~160px 降至 ~80px |
| P3 注意力 | EMA | EMA（保留） | 多尺度空间注意力，小目标定位 |
| P4 注意力 | SimAM | **CoordAtt** | 坐标注意力，对"松动"位移敏感 |
| P2 注意力 | — | **SimAM** | 零参数噪声抑制（微小目标） |
| Backbone P3 | 标准 C3k2 | **C3k2 + LSK** | 自适应感受野，适配不同尺寸螺栓 |
| 损失函数 | CIoU | **Wise-IoU v3** | 动态非单调聚焦，中等质量锚框加权 |

### 2.2 模型规模

| 属性 | v1 | v2 |
|------|-----|-----|
| 参数量 | 9.5M | **9.98M**（+5%） |
| GFLOPs | 23.6 | **33.2**（+41%） |
| 检测头通道 | [256, 512, 1024] | **[64, 128, 256, 512]** |

## 6. 训练过程问题记录

本轮训练经历多次中断和配置调整：

| 时间 | 运行 | 问题 | 原因 | 修复 |
|------|------|------|------|------|
| 07-26 04:02 | 20260726_040214 | Stage 3 每 epoch 2.8h | batch=17 VRAM 溢出（97%），CUDA 交换 | batch 12 |
| 07-27 14:04 | 20260727_140444 | Stage 3 epoch 1 后卡死 | workers=4 DataLoader 死锁（Windows） | workers=0 |
| 07-27 17:21 | 20260727_172156 | Stage 3 epoch 5 后卡死 | 同上（未用 workers=0 命令） | workers=0 写入 YAML |
| 07-27 22:16 | 20260727_221603 | 手动停止 | 优化配置（close_mosaic/copy_paste/epochs） | 调整后重启 |
| 07-27 22:26 | 20260727_222622 | Stage 5 仅 3 epoch | 外部终止 + amp=false 导致 FP32 过慢 | amp=true, batch=8 |
| 07-28 21:31 | 20260728_213145 | ✅ Stage 5 完成 | — | — |

### 关键教训

1. **batch=-1 自动检测不可靠**：P2 四尺度模型 GFLOPs 比 v1 多 41%，自动检测按 v1 显存模型估算导致溢出。必须显式设置 batch。
2. **Windows DataLoader 多进程死锁**：workers≥1 在 Windows 上存在 epoch 间死锁风险。workers=0 是 Windows 上的安全选择。
3. **Stage 5 FP32 过慢**：amp=false 使显存翻倍、速度减半。P2 模型在 FP32 下 batch=12 仍会溢出。改为 amp=true + batch=8。

## 9. 结论与下一步

### 9.1 本轮训练的价值

1. **验证了 v2 架构的可行性**：P2 四尺度 + CoordAtt + LSK 成功训练，无架构级错误
2. **建立了 12 类检测基线**：首次覆盖全部 12 类有标注缺陷，mAP50=0.485
3. **恢复了完整训练流程**：Stage 2→3→4→5 全链路贯通，权重链正确
4. **积累了工程经验**：batch/workers/amp 配置在 P2 模型上的最佳实践

### 9.2 当前模型定位

> **当前模型处于"12 类研发验证"阶段，尚不具备生产部署条件。**

- 适合作为 12 类检测的基线模型
- 适合"高召回候选生成 + 人工复核"的辅助审核模式
- 不适合无人工介入的自动告警

### 9.3 改进方向与完成状态

#### 已完成

| 方向 | 状态 | 说明 |
|------|:----:|------|
| 降低负样本比例至 20-25% | ✅ | 44% → 23.7%（negatives-per-image 10→3） |

#### 下一轮训练改进（聚焦：部件结构特征 + 缺陷表达方式）

当前训练重点是提升模型对**部件结构特点**（用于判断缺陷类型）和**具体缺陷表达方式**（缺失/松动/破损的视觉模式）的学习能力。以下改进围绕这一目标设计：

**🔴 P0 — 类别难度加权（class_weights）**

当前 `class_weights: []` 为空，所有类别等权。"松动"类（VHBNL、SVHBNL、RHTBNL）视觉差异极小，需要更强的学习信号。

```yaml
class_weights:
  - 1.0   # VHBNM（缺失，中等）
  - 1.5   # VHBNL（松动，难）
  - 1.0   # SVHBNM（缺失，中等）
  - 1.5   # SVHBNL（松动，难）
  - 1.3   # SVHTNL（松动，较难）
  - 0.8   # CBHPM（销钉缺失，易）
  - 0.8   # CBVPM（销钉缺失，易）
  - 1.2   # RHTBNM（缺失，样本少）
  - 1.5   # RHTBNL（松动，难+样本少）
  - 1.0   # BSBM（螺栓缺失，中等）
  - 0.9   # INSD（绝缘子破损，特征明显）
  - 1.2   # DRPS（吊弦不受力，形态多变）
```

原理：Focal Loss 处理正负样本不平衡，`class_weights` 进一步处理**类间难度不平衡**。松动类获得 1.5× 梯度权重，迫使模型投入更多容量学习细微差异。预期松动类 mAP +3-5pp。

**🔴 P0 — 结构化正常对照**

当前负样本是随机裁切的"无缺陷区域"（天空、隧道壁、无关金属），模型不知道"同一部件的正常状态长什么样"。

改进：为每个缺陷类别生成**同部件正常对照 crop**——在同一源图中搜索同类型正常部件区域，裁切为对照样本。例如 SVHBNM（螺母缺失）→ 在同一张图中找到正常螺母区域作为"SVHBNM_normal"对照。

效果：模型直接学到"这个部件正常 vs 异常的区别"，而非"随机背景 vs 缺陷"。对 SVHBNM（345 FP 结构混淆）和 SVHBNL（松动与正常难区分）尤其有效。预期结构混淆 FP -30-50%。

**🟡 P1 — 两阶段 Stage 3 训练**

将 Stage 3 拆分为两个学习阶段：

| 子阶段 | Epochs | 增强策略 | 学习目标 |
|--------|:------:|---------|---------|
| 3a: 结构学习 | 1-25 | 强增强（mosaic=0.8, copy_paste=0.5, mixup=0.2, scale=0.4） | 部件结构特征、位置分布、正常模式 |
| 3b: 缺陷精辨 | 26-45 | 轻增强（mosaic=0.1, copy_paste=0.2, mixup=0, scale=0.15） | 缺陷表达细节、正常/异常边界 |

原理：前期强增强建立稳健结构表征，后期轻增强在接近真实分布上精调细微缺陷特征。预期整体 mAP +2-3pp。

**🟢 P2 — 多任务辅助头**

在 Backbone P3 输出后添加轻量**部件类型分类辅助头**：

```
Backbone P3 → [主检测头: 12 类缺陷检测]
           → [辅助分类头: 部件类型分类（7-8 类部件）]
```

辅助头预测"这个区域是什么部件"（螺栓组、销钉、绝缘子、吊弦等），训练权重 0.1-0.3，推理时丢弃。强制 Backbone 学习部件结构特征，间接提升缺陷检测。训练时增加 ~5% 计算量，推理无额外开销。
