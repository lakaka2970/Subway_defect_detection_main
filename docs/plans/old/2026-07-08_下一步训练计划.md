## 3. Phase B: HN 与 FP 抽检

目标不是继续增加 HN 数量，而是判断 HN 是否可靠。

抽检策略:

| Class | 抽检数 | 优先级 |
|---|---:|---:|
| SVHBNM | 80 | P0 |
| CBVPM | 60 | P0 |
| VHBNL | 50 | P1 |
| SVHBNL | 50 | P1 |
| CBHPM | 40 | P1 |
| VHBNM | 30 | P2 |
| SVHTNL | 30 | P2 |

标注类型:

```text
true_negative
missed_gt
boundary_ambiguous
pure_noise
normal_component
```

判定规则:

| 发现 | 决策 |
|---|---|
| `missed_gt` >= 10% | 先修标签，暂停训练 |
| `boundary_ambiguous` >= 20% | 调整 crop/context 策略 |
| `pure_noise` 占主导 | 可作为 state reasoner 负样本 |
| `normal_component` 占主导 | 优先训练 real-vs-fp 二分类器 |

## 4. Phase C: 构建 state reasoner 数据集

保持工程输出 7 类不变:

```text
VHBNM / VHBNL / SVHBNM / SVHBNL / SVHTNL / CBHPM / CBVPM
```

新增内部状态标签:

```text
normal
loose_state
missing_state
structural_anomaly
```

数据来源:

1. YOLO GT crop: 正样本。
2. Stage 5 v2 FP crop: 负样本。
3. 正常螺栓、销钉、阴影、反光、模糊区域: hard normal。

推荐比例:

```text
normal : defect : fp = 2 : 1 : 1
```

必须按 source image split，不能按 crop 随机 split。

## 5. Phase D: 第一版状态推理器

不要直接上复杂 Transformer。先做轻量二分类，证明 cascade 对 Precision 有收益。

优先级:

| 优先级 | 模型 | 目标 |
|---|---|---|
| P0 | ResNet18 | real defect vs FP |
| P0 | MobileNetV3-Small | 快速部署对比 |
| P1 | EfficientNet-B0 | 细粒度状态识别 |
| P2 | MobileViT-S / Swin-Tiny | Transformer 版本 |

第一版训练目标:

| 指标 | 目标 |
|---|---:|
| FP rejection precision | >= 0.85 |
| Real defect recall | >= 0.95 |
| Cascade 后 YOLO Recall 损失 | <= 5pp |

## 8. 停止条件

满足任一条件时，不再继续单独调 YOLO:

1. Stage 5 v2 已完成但 Precision 仍低于 0.35。
2. SVHBNM Precision 仍低于 0.20。
3. 阈值提高导致 Recall 下降超过 5pp。
4. HN 抽检发现明显漏标或边界噪声。

当前已经满足第 1、2 条，所以后续主线应切到 cascade，而不是继续扩大 hard negative。
