# 🧱 1. FP（False Positive）三分类体系设计

> 🎯 目标：让“误检”变成“可学习数据资产”

```python
FP_Type = {

```

---

## 1.2 三类FP定义

### 🔵 FP_LEVEL_1（纹理误检）

```text
来源：
- 金属反光
- 阴影
- 模糊边缘
- 运动伪影

特点：
- YOLO confidence低
- bounding box不稳定
```

✔ 解决方法：

* HN mining
* augmentation

---

### 🟡 FP_LEVEL_2（结构混淆）⭐最重要

```text
normal bolt ↔ loose bolt
normal pin ↔ missing pin
normal base ↔ damaged base
```

✔ 本质：

> ❗结构相似但状态不同

✔ 解决方法：

* Transformer state classifier
* contrastive learning

---

### 🔴 FP_LEVEL_3（语义错误）

```text
VHBNM vs SVHBNM
VHBNL vs SVHBNL
CBVPM vs CBHPM confusion
```

✔ 本质：

> ❗类别体系不适合 detection

✔ 解决方法：

* 改 label system（必须）
* state-based classification

## 1.4 FP自动分类逻辑（vibe coding版本）

```python
def classify_fp(det, gt):
    iou = compute_iou(det, gt)

    if iou < 0.1:
        return "FP_LEVEL_1"

    if iou > 0.3 and det.class != gt.class:
        return "FP_LEVEL_2"

    if det.class_conf < 0.5:
        return "FP_LEVEL_1"

    return "FP_LEVEL_3"
```

## 2.3 模型结构（轻量可部署）

### 推荐：MobileViT-S / Swin-Tiny

```python
class StateTransformer(nn.Module):
    def __init__(self):
        self.backbone = MobileViT_S()
        self.head = nn.Linear(512, 4)

    def forward(self, x):
        return self.head(self.backbone(x))
```

## 3.3 Cascade过滤逻辑

```python
def cascade_filter(yolo_out, transformer):
    final = []

    for det in yolo_out:

        if det.conf < 0.1:
            continue

        crop = extract_crop(det)

        state = transformer(crop)

        if state == "normal":
            continue

        final.append(det)

    return final
```
