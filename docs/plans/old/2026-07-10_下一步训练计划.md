## 4. Phase B: FP/HN 审计

当前 Precision 低，必须先判断误检来源。优先抽检以下类别:

| Class | 当前问题 | 抽检数量 | 优先级 |
|---|---|---:|---|
| SVHBNM | Precision 0.145, mAP50 0.145 | 120 | P0 |
| CBHPM | Precision 0.101, 低阈值误检重 | 100 | P0 |
| CBVPM | Precision 0.179 | 80 | P0 |
| SVHBNL | Precision 0.205 | 60 | P1 |
| VHBNM | Recall 高但 Precision 低 | 60 | P1 |
| VHBNL | 相对较好，做对照 | 40 | P2 |
| SVHTNL | 最佳类，做正样本参照 | 40 | P2 |

审计标签:

```text
true_positive
true_negative
missed_gt
boundary_ambiguous
class_confusion
normal_component
pure_noise
```

决策规则:

| 发现 | 处理 |
|---|---|
| `missed_gt` >= 10% | 先修标签，再训练 |
| `boundary_ambiguous` >= 20% | 调整 crop/context 或标注规范 |
| `class_confusion` 集中在两三类 | 做类别合并/重映射实验或增加类间对比样本 |
| `normal_component` 占主导 | 训练二级 FP 过滤器 |
| `pure_noise` 占主导 | 提高阈值和 NMS/后处理，不急于加训练数据 |

## 5. Phase C: 标签修复与数据增强

下一轮数据版本建议命名:

```text
data/subway_crops_v20260711
```

必须改进:

1. 对 `SVHBNM`、`CBHPM`、`CBVPM` 的 FP 样本回溯到原图，确认是否漏标。
2. 对边界模糊样本统一标注规范，避免同类缺陷在不同图中框大小差异过大。
3. 增加 hard normal: 正常螺栓、阴影、反光、模糊、边缘结构、遮挡部件。
4. 保持 source image split，不按 crop 随机切分，避免泄漏。

建议比例:

```text
defect : hard_normal : fp_reviewed = 1 : 1 : 1
```

## 7. Phase E: 二级 state reasoner / FP filter

当前 YOLO 已经有较高召回，适合接二级过滤器。

第一版不要上复杂 Transformer，先做轻量二分类:

| 模型 | 目标 |
|---|---|
| ResNet18 | real defect vs FP |
| MobileNetV3-Small | 快速部署对照 |
| EfficientNet-B0 | 细粒度状态识别备选 |

训练数据来源:

```text
YOLO TP crop
YOLO FP crop
hard normal crop
边界模糊样本
```

目标:

| 指标 | 目标 |
|---|---:|
| FP rejection precision | >= 0.85 |
| Real defect recall | >= 0.95 |
| Cascade 后 Recall 损失 | <= 5pp |
| Cascade 后 Precision 提升 | >= 10pp |

## 9. 停止条件

满足任一条件时，停止继续单独微调 YOLO:

1. Stage 5b 后 Precision 仍低于 0.35。
2. `SVHBNM` Precision 仍低于 0.20。
3. 阈值提高导致 Recall 下降超过 5pp。
4. FP 审计发现主要问题是漏标或边界标注不一致。

当前最优路线: **先校准阈值，再审计 FP，再做小学习率 Stage 5b；如果 Precision 仍不达标，进入二级 state reasoner。**
