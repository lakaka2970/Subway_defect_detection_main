## 一、7.14 训练结果性能报告

### 1.1 训练流水线概览

7.14 采用新/旧两条多源训练流水线，检测**7类地铁隧道衬砌缺陷**，每阶段使用 YOLO 检测器（输入尺寸 1280×1280，IoU=0.5，min_conf=0.001）：

| 阶段 | 描述 |
|------|------|
| **Stage 2** (new_s2) | 领域自适应后的基线模型 |
| **Stage 3** (new_s3) | 主体训练完成 |
| **Stage 4** (new_s4) | 短精调（short finetune） |
| **Stage 5** (new_s5) | 困难负样本挖掘（hard negative mining） |
| **old_s4** | 旧流水线对照组（20260704模型） |

### 1.7 旧模型（old_s4）失败分析

### 3.3 综合评估

| 维度 | 7.14 训练结果 | 7.25 训练结果 |
|------|-------------|-------------|
| **训练阶段数** | 5（含领域适应） | 3（精简流程） |
| **最佳 mAP@50** | 0.281 | **0.528** ✅ |
| **最佳 mAP@50-95** | 0.166 | **0.377** ✅ |
| **困难类别处理** | SVHBNM/SVHTNL AP<0.10 | 校准后 SVHBNM F2=0.445, SVHTNL F2=0.559 |
| **CBHPM（最优类）** | AP@50=0.713 | F2=0.807 (均衡) |
| **Precision-Recall 平衡** | 偏低 P，中等 R | 校准后可灵活切换 auto/review 工作点 |
| **过拟合风险** | Stage 4→5 mAP 下降 | Stage 4→5 mAP 小幅回落 |
| **FP 控制** | 7.14 F2 点 FP=1130~1182 | 7.25 可通过高阈值 auto 模式大幅压缩 FP |
| **漏检控制** | 7.14 FN=106~127 | 7.25 review 模式下 Recall 普遍更高 |

### 3.4 核心发现

1. **7.25 模型全面超越 7.14**：mAP@50 从 0.281 → 0.528（+88%），mAP@50-95 从 0.166 → 0.377（+127%）—— 说明训练策略、数据配置或模型架构有重大改进。

2. **困难类别显著改善**：7.14 中 SVHBNM（AP=0.070）、SVHTNL（AP=0.078）几乎无法检测；7.25 在 review 模式下分别达到 F2=0.445 和 F2=0.559，具备了实际可用性。

3. **CBVPM 成为最强类别之一**：从 7.14 的 AP@50=0.179 跃升至 7.25 review 工作点 R=0.975 的近乎完美召回。

4. **7.25 的 auto 模式过度保守**：追求 P≥0.9 时多个类别 Recall<5%（VHBNM R=0.022, SVHBNM R=0.009），实际部署应使用 review 工作点或适当降低 Precision 目标。

5. **7.14 的困难负样本挖掘（Stage 5）效果有限**：new_s3→new_s5 的 mAP 没有提升（0.281→0.253），F2 点 TP 仅从 207 增至 209，说明该方向需要重新设计。

6. **7.14 的旧模型（old_s4）完全失效**，但新流水线成功挽救了模型，为 7.25 的改进奠定了基础。
