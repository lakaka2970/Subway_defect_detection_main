> 冻结基线：seed 811 Stage 4 `best.pt`

## 1. 下一轮目标

下一轮不继续无条件堆 epoch 或改结构。先把 8.11 从“稳定的 12 类 crop 研发基线”推进到“数据门禁合格、错误来源可解释、可进行全图验证的 16 类候选”。核心目标：

1. 补齐四个零样本类别并建立真实 source-group 元数据。
2. 将人工复核线整体 Recall 从 0.7457 提升到至少 0.85，随后再冲击 0.90；重点治理 VHBNL、GWCNM、DRPS。
3. 在不牺牲已通过类别的前提下完成 HN、上下文和全图切片的单变量实验。
4. 所有模型与阈值冻结后，再建立一个未使用的新 test；8.11 test 只保留为历史审计集。

## 3. P0：补齐数据与复核

RHTBNM、RHTBNL、GWCSBNM、GWCSBNL 必须达到至少以下正式门禁：

| 拆分 | 每类标注框 | 每类独立 source group |
|---|---:|---:|
| train | ≥300 | ≥100 |
| calibration | ≥80 | ≥30 |
| test | ≥100 | ≥40 |

若只能达到 PoC 门禁（100/30/30 个框），结果必须继续标记为 PoC，不能与正式 16 类基线混称。

### 3.2 全量复核清单

- `ambiguous_review.csv`

本轮 134 个空标签（train 105、calibration 26、test 3）必须逐图确认，疑似漏标样本不得作为负样本。

### 3.3 source 元数据

每张图至少补充 `source_id`、线路、设备、相机、拍摄批次、时间段、光照、类别和复核状态。拆分必须按 source group 完成，禁止连续帧、重复 crop 或同一设备序列跨集合。

## 4. P0：建立下一版冻结数据

建议版本名：`Defect_dataset_813_v1`（实际日期可调整）。输出：

- 文件路径、字节数和 SHA-256 清单；
- 16 类顺序与哈希；
- 每类图数、框数、空标签数、source group 数；

数据门禁未通过时，禁止启动正式三种子训练。

## 5. P1：先做错误归因，不直接训练

从 8.11 calibration 的 `a2_human_review.csv` 和 test 错误明细中，按类别全量整理 VHBNL、GWCNM、DRPS 的 FP/FN：

- 正常同构部件；
- 类间混淆；
- 反光、污渍、锈蚀、加工纹理；
- 裁切边界或目标不完整；
- IoU 不足但类别正确；
- 疑似漏标；
- 远距离、小目标、模糊；
- 重复帧或近重复样本。

疑似漏标和争议样本先复核，不能直接当 hard negative。输出每类 Pareto 图，明确前两大错误来源后才设计实验。

## 6. P1：受控 hard-negative 实验

模型、训练轮数、增强和上下文保持不变，只改变 HN：

| 实验 | HN 设置 |
|---|---|
| H0 | 8.11 基线，不增加 HN |
| H1 | VHBNL/GWCNM/DRPS 各 0.10:1 |
| H2 | 各 0.25:1 |
| H3 | source-balanced，每 source 每类设同一上限 |

先以 seed 809、811 做 3–5 epoch 快筛，两个种子方向一致才进行完整 seed 809/810/811。晋级条件：三类合计 FP 降低≥25%，总 TP 保持率≥98%，任一重点类 Recall 下降≤3 个百分点。

## 7. P1：上下文单变量实验

HN 比例冻结后，再按顺序执行：

| 实验 | 唯一变量 | 重点类别 |
|---|---|---|
| C0 | 当前 crop | 基线 |
| C1 | 1.5×上下文 | VHBNL、CBHPM、GWCNM、DRPS |
| C2 | 2.0×上下文 | 类间混淆和背景 FP |
| C3 | 重叠全图切片 | 跨 crop 漏检、重复框 |

晋级条件：重点弱类 Recall 提升≥3 个百分点、总 FP 增幅≤5%、推理耗时增幅≤20%。上下文实验期间不得同时改检测头或注意力模块。

## 8. P1：类别专项目标

### VHBNL

当前 test 人工复核线 P/R=0.5714/0.5714。优先补充正常/松动/缺失的成对样本，以及反光、遮挡、模糊、远距离、边界裁切和相似部件样本。第一阶段目标：Recall≥0.80 且 Precision≥0.60；第二阶段再冲击 Recall≥0.90。

### GWCNM

当前 test 人工复核线 P/R=0.1961/0.8333。核心问题是高召回时 FP 失控。应先定位 41 个 FP 的主要混淆类别，使用 source-balanced HN，并检查 GWCNM/GWCNL 标签边界与状态定义一致性。目标：Recall 保持≥0.80，同时 Precision 提升到≥0.60。

### DRPS

当前 test 人工复核线 P/R=0.5521/0.6543。需要同时补困难正样本和结构性负样本，重点检查裁切上下文。第一阶段目标：Recall≥0.80、Precision≥0.65。

### GWCNL、INSD、CBHPM

- GWCNL：当前最接近双门槛，但 test Precision=0.9451，需用新来源验证并降低 5 个 FP，不能直接上线。
- INSD：Precision 高，重点补齐 Recall 至≥0.90。
- CBHPM：test 仅 7 个 GT，必须扩充独立来源后再判断，禁止依据小样本 0.857 Recall 作稳定结论。

## 9. P2：三种子复跑与门禁

数据和候选策略冻结后，继续使用 seed 809/810/811，报告：P/R/F1/F2、TP/FP/FN、FP/1000 crops、逐类 AP、逐 source 最差指标和 source-group bootstrap 95% CI。

稳定性门禁保持：

- mAP50-95 RSD≤3%；
- 总 Recall 极差≤5 个百分点；
- VHBNL、GWCNM、DRPS Recall 极差≤8 个百分点；
- 不允许只报告最高种子。

选模仍只使用新 calibration。阈值、NMS 和全图规则冻结后，新 test 只运行一次。

## 10. P2：全图级评估

crop 候选通过后，在未参与训练的 127MP 原图上固定切片尺寸、重叠率、NMS 和跨 crop 合并。按线路、相机、光照、设备和批次分层，报告：

- 逐类 TP/FP/FN/P/R/F2；
- 每张原图 FP 和每 1,000 张原图 FP；
- 跨 crop 重复框率；
- 小目标与边界目标召回；
- 单图延迟、峰值显存和吞吐；
- 最差 source group 及 bootstrap 95% CI。

未通过全图级评估前，不得将 crop 结果称为部署效果。

## 11. P3：结构实验的启动条件

只有完成 16 类数据门禁、HN、上下文和全图基线后，才允许依次比较 P2 小目标检测头、CoordAtt、二阶段过滤器和轻量 Transformer。每次只改一个主要变量。

晋级条件：mAP50-95 提升≥0.02，或在 Recall 保持时总 FP 下降≥20%；三种子方向一致；已通过类别 Recall 下降≤2 个百分点；显存和延迟增幅≤20%。

1. 冻结并备份 8.11 资产与哈希。
