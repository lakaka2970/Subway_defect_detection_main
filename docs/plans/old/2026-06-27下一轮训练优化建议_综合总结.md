# 地铁接触网缺陷检测下一轮训练优化建议综合总结

> 综合来源：本轮训练报告、四阶段训练曲线、Stage 1 与 Stage 2-4 labels 分布图，以及针对下一步训练提出的优化建议。  
> 目标：在当前 `YOLO11m-EMA-SimAM + 多源公开缺陷预训练 + 接触网原生 crop + 四阶段训练` 的基础上，修复训练流程问题，提升小目标类别、低表现类别和整体 Precision/Recall。

---

## 1. 当前训练结果总览

本次新统一训练管线相较 Legacy C1/C2/C3 已经取得明显提升：

| 指标 | Legacy 旧流程 | 新统一流程 | 提升 |
|---|---:|---:|---:|
| mAP50 | 0.377 | 0.497 | +0.120 / +31.8% |
| mAP50-95 | 0.275 | 0.355 | +0.080 / +29.1% |
| 最佳类别 | — | CBHPM 0.767、VHBNM 0.720 | — |
| 最弱类别 | — | SVHBNM 0.251、SVHBNL 0.366、VHBNL 0.386、CBVPM 0.404 | — |

四阶段训练的最好结果如下：

| 阶段 | 目标 | 最佳 mAP50 | 最佳 mAP50-95 | 主要结论 |
|---|---|---:|---:|---|
| Stage 1 | 公开缺陷 generic_defect 预训练 | 0.838 | 0.597 | 公开缺陷数据训练充分、收敛稳定 |
| Stage 2 | 接触网 7 类领域适配 | 0.462 | 0.325 | 有效适配，但未继承 Stage 1 权重 |
| Stage 3 | 1280 主训练 | 0.504 | 0.353 | 主提升阶段，后半段开始过拟合 |
| Stage 4 | 低学习率短微调 | 0.499 | 0.355 | 收益很小，且存在 bias warmup 学习率异常 |

总体判断：

1. 当前训练路线是有效的，原生 crop、多源数据和 AdamW 训练已经显著优于旧流程。
2. 当前上限仍被几个明确问题限制：Stage 1 权重未传递、Stage 4 warmup 学习率异常、小目标三尺度检测不足、难负样本不足、部分类别标注/视觉可分性不足。
3. 下一轮不应简单延长训练，而应优先修复流程错误并做结构与数据消融。

## 2. Label 分布补充分析

### 2.1 Stage 1 公开缺陷预训练 labels

Stage 1 使用 DeepPCB + NEU-DET + GC10-DET 混合公开数据集，并将所有缺陷类别统一合并为 `generic_defect`。

| 项目 | 数值 |
|---|---:|
| 类别数 | 1 类：generic_defect |
| 实例数 | 13,817 |
| 用途 | 学习通用工业异常纹理与缺陷定位能力 |

关键观察：

1. Stage 1 不存在类别不平衡问题，因为所有公开缺陷均被合并为单类。
2. 公开缺陷数据中的目标位置较分散，中心区域略密集，适合训练通用缺陷定位能力。
3. 目标尺度集中在较小区域，说明公开数据中也包含大量小目标或局部异常区域，与接触网小缺陷存在一定迁移价值。
4. DeepPCB 更偏规则结构缺陷，GC10-DET 和 NEU-DET 更偏金属表面纹理缺陷，因此 Stage 1 的合理定位是“工业异常纹理预训练”，而非直接替代接触网目标域训练。
5. 本次最大遗憾是 Stage 2 未继承 Stage 1 权重，导致 13,817 个公开缺陷实例学到的知识没有有效传入接触网 7 类训练。

### 2.2 Stage 2-4 接触网 labels

Stage 2-4 使用相同的 `subway_crops` 数据集，共有 7 类、5,234 个接触网缺陷实例。

| 类别 | 实例数 | 占比 | 训练表现观察 |
|---|---:|---:|---|
| VHBNM | 987 | 18.86% | 表现好，mAP50 约 0.720 |
| VHBNL | 673 | 12.86% | 松动类，表现偏低，mAP50 约 0.386 |
| SVHBNM | 1,197 | 22.87% | 数量最多但表现最差，mAP50 约 0.251 |
| SVHBNL | 362 | 6.92% | 数量最少且为松动类，mAP50 约 0.366 |
| SVHTNL | 773 | 14.77% | 表现中等偏好，mAP50 约 0.584 |
| CBHPM | 701 | 13.39% | 表现最好之一，mAP50 约 0.767 |
| CBVPM | 541 | 10.34% | 表现偏低，mAP50 约 0.404 |
| **合计** | **5,234** | **100%** | — |

类别分布最大/最小比例约为 `1197 / 362 ≈ 3.31:1`。因此当前接触网数据存在中等类别不均衡，但不是极端长尾。

### 2.3 Label 分布带来的核心结论

#### 结论 1：SVHBNM 不是单纯样本数量问题

SVHBNM 拥有 1,197 个实例，是训练集中数量最多的类别，但 mAP50 却最低。这说明 SVHBNM 的瓶颈更可能来自：

- 目标尺寸极小；
- 缺失状态与正常槽钢底座、螺母边缘、阴影、反光混淆；
- 标注框尺度或类别定义可能不够一致；
- 三尺度 P3/P4/P5 模型对该类小目标不够敏感；
- 负样本不足，导致正常结构被误判为缺陷。

因此，SVHBNM 下一步应优先做标注质量排查、P2 小目标模型对照、hard negative mining，而不是简单补更多同类正样本。

#### 结论 2：SVHBNL 是明确的少样本与细粒度双重问题

SVHBNL 只有 362 个实例，是 7 类中最少的类别，同时又属于“松动”状态识别。该类应优先进行：

- 类别重采样；
- 补充标注；
- 正常螺母难负样本加入；
- 结构上下文更大的 crop；
- 二级分类或关键点辅助验证。

#### 结论 3：松动类不只是检测问题，更是状态识别问题

VHBNL 和 SVHBNL 的视觉差异不是“有无目标”，而是螺母位置、角度、缝隙、相对偏移等细粒度状态变化。普通 YOLO 检测头可能难以稳定识别，应考虑：

- `normal / loose / missing` 二级分类器；
- 保留更大结构上下文；
- 降低会破坏角度语义的强旋转、随机翻转；
- 对松动类进行专项验证集分析。

#### 结论 4：CBHPM 与 CBVPM 的差异说明“类别视觉可分性”比样本数更关键

CBHPM 数量中等但表现最好，说明其缺陷形态明显、背景稳定、标注一致性较好。CBVPM 数量不算极少却效果偏低，说明垂直销钉缺口更依赖视角、结构上下文和完整销钉负样本。

#### 结论 5：位置分布存在结构性聚集

Stage 2-4 的 `x-y` 热力图显示目标并非均匀分布，而是集中在若干固定区域。这反映接触网结构件在 crop 中存在位置规律，也可能来自 crop 生成策略。该规律有助于模型学习场景先验，但也可能导致位置偏置，降低对非常规位置缺陷的泛化能力。

建议下一轮加入“位置去偏置 crop”：让同一缺陷在 crop 中出现在中心、边缘、左上、右上、左下、右下等多种位置。

## 3. 当前训练中的关键问题诊断

### 3.1 严重问题：Stage 2 未继承 Stage 1 权重

本次训练报告显示 Stage 2 的 `pretrained` 指向 `weights/yolo11m.pt`，而不是 Stage 1 的 `best.pt`。这意味着公开缺陷预训练没有被真正用于接触网训练。

影响：

- Stage 1 的 13,817 个 generic_defect 实例训练收益没有传递；
- Stage 2 实际从 COCO 权重直接进入接触网 7 类；
- 当前最终 mAP50=0.497 是在 Stage 1 未被充分利用的情况下取得的，修复后仍有提升空间。

下一轮必须修复：

```text
Stage 2 pretrained from: output/<run>/stage1/weights/best.pt
Source nc=1, target nc=7
Load backbone + neck + attention weights
Reinitialize Detect classification layers
```

---

### 3.2 新发现问题：Stage 4 bias warmup 学习率异常高

Stage 4 设定为极低学习率短微调，`lr0=3e-5`，但实际 CSV 中 bias 参数组前两轮学习率异常高：

```text
epoch 1: lr/pg0=1e-5, lr/pg1=1e-5, lr/pg2=0.066929
epoch 2: lr/pg0=2e-5, lr/pg1=2e-5, lr/pg2=0.033606
epoch 3: lr/pg0=3e-5, lr/pg1=3e-5, lr/pg2=0.000282
epoch 4+: lr/pg2≈3e-5
```

这会破坏“低学习率、零增强、真实分布微调”的目的。

下一轮 Stage 4 应设置：

```yaml
warmup_epochs: 0
warmup_bias_lr: 0.00001  # 或与 lr0 完全一致
```

并增加训练启动检查：

```text
如果 Stage 4 第 1 轮 lr/pg2 > 10 * lr0，则自动停止训练。
```

---

### 3.3 Stage 3 后半段过拟合

Stage 3 的最佳 mAP50 出现在约 epoch 40，最佳 mAP50-95 出现在约 epoch 57。之后训练 loss 继续下降，但验证指标回落，说明模型开始记忆训练集。

下一轮建议：

```yaml
epochs: 80
patience: 25-30
close_mosaic: 35
```

而不是继续跑 120 epoch。

---

### 3.4 当前 Precision 偏低，难负样本不足

Stage 4 All Precision 约 0.439，明显低于项目目标。当前训练中正样本 crop 占主导，正常螺母、正常销钉、反光、阴影、模糊边缘、切片边界伪影等难负样本不足。

下一轮必须增加 Stage 5 hard negative mining。

---

### 3.5 当前三尺度模型对极小目标仍可能不足

当前 YOLO11m-EMA-SimAM 使用 P3/P4/P5 三尺度检测。结合 label 的 `width-height` 分布，以及 SVHBNM、SVHBNL、CBVPM 等小目标类别偏低，下一轮必须至少做一次 P2 四尺度模型对照实验。

---

## 4. 下一轮训练总体策略

下一轮不要直接只跑一个“大而全”的实验，而应分为两个主线：

```text
Run A：修复版 YOLO11m-EMA-SimAM，不改模型结构
Run B：YOLO11m-P2-EMA-SimAM，验证 P2 对小目标类别的收益
```

推荐最小实验矩阵：

| 实验 | 模型 | 目的 | 是否必跑 |
|---|---|---|---|
| A1 | YOLO11m-EMA-SimAM | 修复 Stage 继承与 warmup，验证流程收益 | 必跑 |
| A2 | A1 + Hard Negative Mining | 验证 Precision 提升 | 必跑 |
| B1 | YOLO11m-P2-EMA-SimAM | 验证 P2 对小目标提升 | 必跑 |
| B2 | B1 + Hard Negative Mining | 冲最终指标 | 必跑 |

优先顺序：

```text
A1 → B1 → B2 → A2
```

如果 A1 已经明显超过当前结果，再投入更多精力做 P2 和 HNM；如果 A1 仍卡在 0.50 附近，应优先排查 Stage 1 权重是否真正部分加载成功、标注质量和类别定义。

### 5.6 Stage 5：Hard Negative Mining

目的：提升 Precision，减少正常结构误报。

步骤：

```text
1. 用 Stage 4 best.pt 跑所有 train 源图、未标注图、正常巡检图；
2. 收集 conf=0.15–0.70 的误检框；
3. 人工快速确认其中真实正常区域；
4. 生成 negative crop，标签为空；
5. 加入 subway_crops_hnm；
6. 低学习率再训练 20 epoch。
```

配置：

```yaml
name: stage5_hard_negative
data: subway_crops_hnm.yaml
pretrained: output/<run>/stage4_true_finetune/weights/best.pt

epochs: 20
imgsz: 1280
batch: 12-15

optimizer: AdamW
lr0: 0.00002
lrf: 1.0
cos_lr: false
warmup_epochs: 0
warmup_bias_lr: 0.00002

freeze: [0,1,2,3,4,5,6,7]
mosaic: 0.0
mixup: 0.0
copy_paste: 0.0
erasing: 0.0

patience: 6
```

建议重点收集以下负样本：

- 正常螺母；
- 正常销钉；
- 完整但反光的金属边缘；
- 阴影遮挡区域；
- 运动模糊区域；
- 切片边界伪影；
- 正常但姿态接近“松动”的螺母；
- 与 SVHBNM、VHBNL、CBVPM 高度相似但实际正常的结构。

## 6. P2 四尺度模型实验建议

当前三尺度模型为：

```text
P3 / P4 / P5
```

下一轮建议增加：

```text
P2 / P3 / P4 / P5
```

推荐注意力布局：

| 尺度 | 推荐模块 | 目的 |
|---|---|---|
| P2/4 | SimAM | 微小缺陷局部异常增强 |
| P3/8 | EMA | 小目标定位与上下文增强 |
| P4/16 | SimAM 或 ECA | 中尺度结构辅助 |
| P5/32 | ECA 或无注意力 | 大结构背景语义 |

重点观察类别：

| 类别 | 当前 mAP50 | P2 目标 |
|---|---:|---:|
| SVHBNM | 0.251 | 0.35+ |
| SVHBNL | 0.366 | 0.45+ |
| VHBNL | 0.386 | 0.48+ |
| CBVPM | 0.404 | 0.50+ |

判断逻辑：

- 如果 P2 明显提升上述类别，说明主要瓶颈来自小目标特征分辨率；
- 如果 P2 提升有限，说明主要瓶颈更可能是标注质量、类别定义、难负样本不足或视觉可分性不足。

## 7. 类别级专项优化

### 7.1 SVHBNM

当前问题：数量最多但表现最差。

优先操作：

1. 抽查 SVHBNM 标注质量；
2. 检查是否存在正常螺母误标为缺失；
3. 检查 bbox 是否过大、过小或偏移；
4. 可视化 SVHBNM Top FP / Top FN；
5. 增加正常槽钢底座 hard negative；
6. 使用 P2 模型验证小目标尺度问题；
7. 做 3–5 倍 class-aware crop oversampling，但不要盲目提高原始采样权重。

### 7.2 VHBNL / SVHBNL

当前问题：松动类细粒度判别困难。

优先操作：

1. 增加正常螺母负样本；
2. 松动类 crop 保留更大上下文；
3. 减少强旋转与随机翻转；
4. 建立 `normal / loose / missing` 二级分类器；
5. 对松动类进行类别重采样；
6. 补充 SVHBNL 标注。

### 7.3 CBVPM

当前问题：视角依赖强，垂直销钉缺口可见性弱。

优先操作：

1. 增加完整垂直销钉负样本；
2. 加入相邻帧或相邻切片样本；
3. 对同一销钉区域做多尺度 crop；
4. 保留轻微旋转增强，但避免过大角度；
5. 如果 P2 提升不明显，考虑二阶段 ROI 分类。

## 8. 数据采样与 crop 生成建议

### 8.1 类别重采样建议

| 类别 | 建议采样权重 |
|---|---:|
| SVHBNL | 2.0 |
| CBVPM | 1.5 |
| VHBNL | 1.3 |
| SVHBNM | 1.0 |
| VHBNM | 1.0 |

注意：SVHBNM 虽然表现最差，但数量最多，不建议简单提高采样权重，以免放大潜在标注噪声和背景混淆。

### 8.2 位置去偏置 crop

下一轮 crop 生成时，应让同一缺陷出现在不同空间位置：

```text
center crop
left-top crop
right-top crop
left-bottom crop
right-bottom crop
near-edge crop
```

建议规则：

- 每个缺陷至少生成 3–5 个随机偏移 crop；
- 强制一部分缺陷靠近 crop 边缘；
- 训练集随机位置扩展，验证集保持固定策略；
- 同时加入结构位置相同但无缺陷的 negative crop。

## 12. 一句话总结

下一轮训练的核心不是“继续堆 epochs”，而是：

```text
修复公开预训练继承链路
+ 修复低学习率微调的 warmup 异常
+ 用 P2 验证小目标瓶颈
+ 用 hard negative mining 提升 Precision
+ 用 label 分布驱动类别级优化
```

其中最关键的新结论是：

```text
SVHBNM 数量最多但效果最差，说明它不是样本数量问题，而是小目标尺度、背景混淆、标注一致性和模型尺度分辨率问题；
SVHBNL 才是更明确的少样本 + 松动状态细粒度识别问题。
```
