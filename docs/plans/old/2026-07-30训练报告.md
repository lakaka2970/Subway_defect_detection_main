**分析：**

- **结论：结构学习阶段的目标（建立稳健部件表征）已达成，但精度需要后续阶段精调**

### 5.2 7/28 → 7/30 对比分析

| 指标 | 7/28 | 7/30 | 变化 | 分析 |

**核心发现：**

1. **Recall 显著提升 +8.9%**：两阶段 Stage 3（特别是 3a 的强增强 + class_weights）有效提升了模型对难检缺陷的覆盖率。这是本次训练最重要的成果。

2. **Precision 下降 −7.0%**：Recall 的提升以 Precision 为代价。更多检出意味着更多误检。这是 Recall-Precision 权衡的典型表现。

3. **mAP50 基本持平**：两阶段策略未能在 mAP50 上超越 7.28 的单阶段 45 epoch 训练。说明 45 epoch 混合增强在总体检测质量上仍有优势。

4. **mAP50-95 下降**：定位精度轻微退步，可能与 3a 阶段的强 mosaic（0.8）导致边界框回归质量下降有关。

**关键观察：**
- **DRPS（吊弦不受力）是唯一达标类**：样本最多（295 GT），视觉特征独特
- **CBHPM 最接近达标**：高精度模式 P=0.91/R=0.74，Recall 仅差 16pp
- **RHTBNM/RHTBNL 几乎不工作**：样本极少（56/46 GT），P<0.20
- **VHBNM/VHBNL 高精度模式下 Recall 极低**（<0.05），说明模型对这两类的置信度分布非常分散

### 6.3 差距根因分析

**Precision 差距（−46.4pp）是最大瓶颈：**

| 根因 | 影响估计 | 证据 |
|------|:-------:|------|
| 数据集规模不足（~10K crops vs 工业级 50K+） | ~15pp | 7/25 用 52K crops 时 P=0.478 |
| 负样本/背景比例不足（23.7%） | ~10pp | 正常部件未被充分学习 |
| 类别不均衡（RHTBNM/RHTBNL 极少样本） | ~5pp | 少样本类 AP 接近 0 |
| 标注质量（VHBNM/VHBNL 边界模糊） | ~5pp | 分类器 F1=0.499 |
| 模型容量（9.98M 参数） | ~5pp | 对比更大模型的潜力 |
| 训练策略（未用难负样本、无对照 crop） | ~6pp | Stage 5 无效 |

**Recall 差距（−26.6pp）：**

| 根因 | 影响估计 | 证据 |
|------|:-------:|------|
| 小目标漏检（P2 头仍有不足） | ~10pp | 微小缺陷在 1280px 下仍难检出 |
| 少样本类 Recall 极低 | ~8pp | RHTBNM/RHTBNL/DRPS 几乎不检出 |
| 遮挡/模糊场景覆盖不足 | ~5pp | 数据集缺少恶劣条件样本 |
| 模型结构表达力 | ~3pp | 部件结构特征学习不充分 |

## 7. 关键发现与问题诊断

### 7.1 成功经验

1. **两阶段 Stage 3 验证有效**：3a（结构学习）→ 3b（缺陷精辨）的策略成功将 Recall 提升至 0.634（历史最高），证明了"先强增强建结构、后轻增强精判别"的训练思路。

2. **Class weights 发挥作用**：松动类（1.5×）和少样本类（1.2×）的加权在 3a/3b 阶段持续生效，Recall 的提升部分归因于此。

3. **WDDM 修复解决训练卡死**：TdrDelay=60s + HAGS 关闭后，训练稳定性显著改善。Stage 4 在修复前卡死，修复后完整完成 15 epoch。

4. **Stage 4 恒定低 LR 策略持续有效**：lr=5e-5 + lrf=1.0（无衰减）在 15 epoch 内指标全程上升，未出现过拟合。

5. **Pipeline 自动权重链解析**：Stage 4 自动解析 3b 权重的逻辑正确工作，避免了手动指定路径的错误风险。

### 7.2 问题诊断

1. **Stage 5 完全无效（最严重问题）**
   - 未采集难负样本就直接运行 Stage 5，等于用相同数据以超低 LR 重复训练
   - 结果：mAP50 下降 1.7pp，Recall 暴跌 10.8pp
   - **修复：已实现 `collect_hard_negatives.py`（12 类）+ `mix_hard_negatives.py` 自动化流程**

2. **Precision 持续偏低（<0.45）**
   - 连续 5 次训练 Precision 均未超过 0.50
   - 根因：负样本比例不足（23.7%），模型对正常部件的判别能力弱
   - **需要：正常对照 crop + 难负样本 + 级联分类器三重手段**

3. **少样本类几乎不工作**
   - RHTBNM、RHTBNL 样本极少，AP 接近 0
   - class_weights 的 1.2×/1.5× 加权不足以弥补数据量的绝对不足
   - **需要：针对性数据扩充或合并类别**

4. **mAP50 未能超越 7.28**
   - 两阶段策略提升了 Recall 但牺牲了 Precision 和 mAP
   - 可能需要调整 3a/3b 的 epoch 比例或增强强度

## 8. 已实施改进的适配性评估

### 8.1 多任务辅助头（部件类型分类）

| 维度 | 评估 |
|------|------|
| **针对问题** | 模型对部件结构特征学习不充分 |
| **适配性** | ⭐⭐⭐⭐ 高度适配 |
| **预期效果** | backbone P3 学习"图像中有哪些部件"的全局信号，提升结构判别能力 |
| **风险** | 辅助损失权重（0.1）需要调优；可能轻微增加训练时间 |
| **与性能特点的匹配** | Recall 高但 Precision 低 → 辅助头帮助模型更好理解部件结构，减少将非部件区域误检为缺陷 |

**结论：高度适配。** 当前模型的主要问题是"知道缺陷长什么样，但不确定是不是那个部件"。辅助头直接强化了部件识别能力。

### 8.2 分类器层级化（VHBNM/VHBNL）

| 维度 | 评估 |
|------|------|
| **针对问题** | VHBNM/VHBNL 4 类分类器 F1=0.499 |
| **适配性** | ⭐⭐⭐⭐⭐ 完全适配 |
| **预期效果** | 二分类 L1（normal/defective）预期 F1>0.85；L2（missing/loose）预期 F1>0.70 |
| **风险** | L2 训练数据量可能不足（仅缺陷样本） |
| **与性能特点的匹配** | Precision=0.436 的最大拖累来自 VHBNM/VHBNL 的高误检率。层级分类器可在推理阶段过滤 50%+ 的假阳性 |

**结论：完全适配。** 直接解决了 Precision 最低的两个类别的误检问题。消除了"ambiguous"标注伪影。

### 8.3 Stage 5 难负样本采集改进

| 维度 | 评估 |
|------|------|
| **针对问题** | Stage 5 未采集难负样本导致负效果 |
| **适配性** | ⭐⭐⭐⭐⭐ 完全适配 |
| **预期效果** | 正确的难负样本训练可提升 Precision 5-10pp，同时控制 Recall 损失在 3pp 以内 |
| **风险** | 难负样本质量取决于 Stage 4 模型的 FP 分布 |
| **与性能特点的匹配** | Precision=0.436 → 大量 FP 可被采集为高质量难负样本 |

**结论：完全适配。** 当前 Precision 越低，可采集的难负样本越多，Stage 5 的改进潜力越大。

### 8.4 综合适配性判断

三项改进形成了**互补的 Precision 提升链**：

```
训练阶段:  辅助头 → 更好的部件结构理解 → 减少结构性误检
                                          ↓
Stage 5:   难负样本 → 学习真实 FP 分布 → 减少场景性误检
                                          ↓
推理阶段:  层级分类器 → 逐检测二次验证 → 过滤残余误检
```

预期综合效果：Precision 从 0.436 提升至 **0.55-0.65** 范围，同时 Recall 损失控制在 2-3pp 以内。
