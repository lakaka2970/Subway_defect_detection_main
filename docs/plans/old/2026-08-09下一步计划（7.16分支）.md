> **依据**：`docs/plans/8.9分析报告.md`

> **总原则**：先补齐数据与修复标签，再做稳定性复跑和误报治理；冻结 8.9 test，不使用其结果继续调参

## 1. 下一轮总目标

下一轮不以“继续堆叠网络结构”为首要任务，而是完成以下三件事：

1. 让 16 个类别全部具备真实、可配对、来源隔离的训练/calibration/test 样本。
2. 在新 calibration 上稳定提高 Precision 与 Recall，重点压低 DRPS、VHBNL、BSBM 的 FP，并补强 VHBNL、CBHPM、INSD 的 Recall。
3. 建立多种子、双工作点、全图级评估闭环，避免用单次 crop 指标代替部署结论。

## 2. 冻结规则

### 2.1 冻结 8.9 test

8.9 test 已经用于最终评估。从现在开始：

1. 不再根据 8.9 test 的逐类表现修改阈值、增强、采样或模型结构。
2. 8.9 test 只作为历史审计集，后续候选可在最终冻结后做一次回归检查，但不能据此选择候选。
3. 新增或修订数据先进入 `candidate_pool_810`，完成双人复核后再生成新的 train/calibration/test。
4. 下一轮全部模型选择、阈值选择和早停判断只使用新 calibration。
5. 新 test 在模型、阈值、NMS 和全图推理规则全部冻结后只运行一次。

## 3. P0：修复数据配对和零样本类别

### 3.1 处理 45 个孤立标签

对每个孤立标签执行以下检查：

1. 在原始采集盘、导出目录和历史备份中按完整文件名、时间戳和近似文件名查找原图。
2. 检查图片扩展名差异、括号/下划线差异、中文或空格、重复导出后缀及大小写差异。
3. 找到原图后进行尺寸读取、标注框可视化和人工复核，不允许仅按文件名自动配对。
4. 找不到原图的标签标记为 `orphan_unrecoverable`，不得进入训练。
5. 将修复映射保存为 `orphan_recovery_manifest.csv`，记录旧标签名、原图名、处理结论和复核人。

四个零样本类别的恢复优先级最高：

| 类别 | 当前全部标签框 | 当前可用框 | 下一步 |
|---|---:|---:|---|
| RHTBNM | 3 | 0 | 恢复原图并新增采集 |
| RHTBNL | 7 | 0 | 恢复原图并新增采集 |
| GWCSBNM | 3 | 0 | 恢复原图并新增采集 |
| GWCSBNL | 5 | 0 | 恢复原图并新增采集 |

即使 18 个现有框全部恢复，也不足以支撑训练，仍必须新增独立来源样本。

### 3.2 审核未标注图和空标签

- 对 117 张未配标签原图逐张确认：确实无缺陷、漏标、导出遗漏或损坏。
- 对 64 个空标签文件逐张可视化，确认其是否为可靠纯背景。
- 疑似漏标图不得作为负样本；先进入 `needs_review`。
- 双人复核不一致的样本进入 `ambiguous`，不进入自动提报训练集。
- 输出 `unlabelled_review.csv`、`empty_label_review.csv` 和修订前后数量对比。

### 3.3 最低数据门禁

以独立 source group 为统计单位，不能用相邻帧、重复 crop 或增强图替代独立样本。

| 类别状态 | train 目标 | calibration 目标 | test 目标 |
|---|---:|---:|---:|
| 四个当前零样本类 | 每类≥300个框且≥100个 source group | 每类≥80个框且≥30个 source group | 每类≥100个框且≥40个 source group |
| VHBNM、CBHPM | 每类≥300个框 | 每类≥80个框 | 每类≥100个框 |
| 其他已有类别 | 不低于当前数量，并补充困难正/负样本 | 每类≥80个真值 | 每类≥100个真值 |

若短期无法达到正式目标，可先建立“可行性门禁”：每个新类别至少 100 个 train 框、30 个 calibration 框、30 个 test 框；但此时只能做 PoC，不得做生产结论。

## 4. P0：建立新数据版本和冻结拆分

### 4.1 数据版本

完成数据修订后建立新版本，例如 `Defect_dataset_810_v1`，并保存：

- 文件相对路径、字节数和 SHA-256 清单；
- classes.txt 的 16 类顺序和哈希；
- 每个样本的 `source_id`、线路、设备、拍摄批次、类别和复核状态；
- 每类框数、图数、source group 数；
- orphan、empty、unlabelled、invalid、duplicate 的审计结果。

任何训练运行都必须在 manifest 中记录数据版本和哈希，禁止直接在同一目录内静默修改标签。

### 4.2 新拆分

1. 按 `source_id` 分组，禁止同一设备、同一连续拍摄序列跨 train/calibration/test。
2. 对 16 类做分层分组拆分，同时平衡线路、相机、光照和拍摄批次。
3. 新拆分生成后运行泄漏检查，三个交集必须为 0。
4. calibration 与 test 的每类真值未达到门禁时，不允许启动正式训练。
5. 8.9 test 不合并到新 calibration；如需复用，只能作为历史回归集。

## 5. P0：建立可重复的 16 类基线

### 5.1 基线配置

在数据修复后先复现当前策略，不立即改变模型结构：

- 16 类输出顺序保持不变；
- Stage 3 15 epoch + Stage 4 5 epoch；
- imgsz=1280；
- 纯背景比例保持 22.5%；
- 其余优化器、学习率、冻结层和增强参数与 8.9 一致；
- 固定 worker seed、数据顺序和 CUDA/CuDNN 随机源。

### 5.2 三种子实验

至少运行 seed 809、810、811 三个种子，报告：

- Precision、Recall、F1、F2、mAP50、mAP50-95；
- TP、FP、FN、每 1,000 crops 的 FP；
- 每类 P/R/F2 和 AP；
- 三种子均值、标准差、极差和 RSD；
- 每个 source group 的最差指标；
- source-group bootstrap 95% CI。

稳定性门禁：

- mAP50-95 RSD≤3%；
- 总 Recall 极差≤5 个百分点；
- 任一重点类 Recall 极差≤8 个百分点；
- 不允许只选择最高种子报告。

## 6. P1：误报治理实验

### 6.1 优先类别

人工复核线中，DRPS、VHBNL、BSBM 合计占 66.48% FP，应作为第一批治理对象。

将三类 FP 全量导出并分层：

- 正常同构部件；
- 类间混淆；
- 反光、污渍、锈蚀或加工纹理；
- 裁切边界和目标不完整；
- IoU 不足但类别正确；
- 疑似漏标；
- 重复帧或近重复样本；
- 远距离、小目标和严重模糊。

疑似漏标和争议样本必须先复核，不能直接作为 hard negative。

### 6.2 受控 hard-negative 实验

| 实验 | 唯一变量 | 配置 |
|---|---|---|
| H0 | 基线 | 不额外加入 HN |
| H1 | 低比例 HN | 三类各按 HN:正样本=0.10:1 |
| H2 | 中比例 HN | 三类各按 HN:正样本=0.25:1 |
| H3 | source-balanced HN | 每 source、每类设置相同上限 |

每组先训练 3～5 epoch 快筛，至少两个种子方向一致才进入完整三种子训练。

晋级条件：

- DRPS、VHBNL、BSBM 合计 FP 降低≥25%；
- 总 TP 保持率≥98%；
- 任一重点类 Recall 下降≤3 个百分点；
- 新增 HN 中人工确认率为 100%；
- 不能以提高阈值掩盖模型本身的 Recall 下降。

## 7. P1：漏检和弱类补强

### 7.1 VHBNL

VHBNL 同时有 111 FP 和 29 FN，是首要难类。采集和复核应覆盖：

- 正常、松动、缺失的成对样本；
- 同型号、相似角度和相近光照下的状态对照；
- 反光、遮挡、模糊、远距离和边界裁切；
- 容易与 VHBNM、SVHBNM、SVHBNL 混淆的结构。

目标：人工复核线 Recall≥0.85，且在该 Recall 下 Precision≥0.60；达到后再向双 0.90 推进。

### 7.2 CBHPM

CBHPM 从 calibration 的 P=0.9375、R=1.0000 降到 test 的 P=1.0000、R=0.4667。下一步需：

1. 补充不同线路、设备、光照和拍摄批次的正样本；
2. 对 8 个 FN 全量复核并分类原因；
3. 检查目标裁切是否缺少安装基座和邻接结构；
4. 比较 1.0×、1.5×、2.0×上下文 crop，模型结构保持不变；
5. 使用 source-group bootstrap 评估小样本波动。

### 7.3 INSD

INSD 人工复核线 P/R 均为 0.50。应分别增加困难正样本和同构正常负样本，并检查它与 DRPS、BSBM 或背景纹理的混淆。补数前不建议单纯延长 epoch。

### 7.4 CBVPM 与 SVHTNL

- CBVPM 已接近门槛，先通过新增独立来源和三种子验证稳定性，不做大幅结构修改。
- SVHTNL 已达到双 0.90，进入影子验证和漂移监控；新实验若使其 Recall 下降超过 2 个百分点，候选不晋级。

## 8. P1：上下文与裁切单变量实验

当前 crop 可能丢失部件之间的结构关系。按以下顺序实验：

| 实验 | 唯一变量 | 重点观察 |
|---|---|---|
| C0 | 当前紧密 crop | 基线 |
| C1 | 1.5×上下文 | VHBNL、CBHPM、INSD Recall |
| C2 | 2.0×上下文 | 类间混淆与背景 FP |
| C3 | 重叠全图切片参数 | 全图漏检和跨 crop 重复框 |

晋级条件：重点弱类 Recall 提升≥3 个百分点、总 FP 增幅≤5%、推理耗时增幅≤20%。裁切尺度实验期间禁止同时更改注意力模块、检测头或 HN 比例。

## 9. P2：模型结构实验顺序

只有在数据门禁、三种子稳定性和裁切实验完成后，才允许比较模型结构：

1. 当前 Stage 4 基线；
2. P2 小目标检测头；
3. CoordAtt 替换当前注意力模块；
4. 二阶段轻量分类器过滤结构性 FP；
5. MobileViT/轻量 Transformer，仅用于状态判断确实依赖长程上下文的类别。

每次只修改一个主要变量。模型结构晋级必须同时满足：

- mAP50-95 提升≥0.02，或在 Recall 保持的情况下总 FP 降低≥20%；
- 三种子方向一致；
- 任一已通过类别 Recall 下降≤2 个百分点；
- 显存和单图延迟增幅≤20%。

## 10. 阈值与业务路由

每类继续保留两条 calibration 冻结阈值：

- **自动提报线**：以 Precision≥0.95 为首要门槛，并要求 Recall≥0.80；
- **人工复核线**：以 Recall≥0.90 为首要门槛，在此约束下最大化 Precision/F2。

建议下一阶段业务路由：

- SVHTNL：可进入离线影子自动提报验证；
- CBVPM：人工复核，待三种子和新来源验证后再决定是否影子上线；
- VHBNM、VHBNL、SVHBNM、SVHBNL、GWCNM、GWCNL、BSBM、INSD、DRPS、CBHPM：仅人工复核和错误挖掘；
- RHTBNM、RHTBNL、GWCSBNM、GWCSBNL：禁用输出或强制标记为“未训练”，直至补齐数据并重新训练。

## 11. 全图级评估

crop 级候选通过后，必须在未参与训练的 127MP 原图上完成端到端评估：

1. 固定切片尺寸、重叠率、NMS、跨 crop 合并和阈值；
2. 按线路、相机、光照、设备和拍摄批次分层；
3. 报告逐类 TP/FP/FN/P/R/F2、每张原图 FP、每 1,000 张图 FP；
4. 报告候选框数、GPU 显存、平均/中位/P95 推理耗时；
5. 输出逐类 TP/FP/FN 可视化包，每个有效类别至少 50 例；
6. 检查跨 crop 重复框、边缘漏检和小目标漏检。

全图级 Recall 显著低于 crop 级时，优先修复切片与候选生成，不继续堆叠检测器结构。

## 15. 停止条件

- 数据门禁未通过时，不启动正式 16 类训练。
- 连续两个单变量实验未改善目标类 P/R 或 FP 时，停止该路线，回到错误样本和标签质量分析。
- 任一实验使已通过类别 Recall 下降超过 2 个百分点，立即停止晋级。
- HN 增加后总 TP 保持率低于 98%，停止扩大 HN。
- 三种子 RSD>3% 时，不宣称小于 1 个百分点的改动有效。
- 全图 Recall 明显低于 crop Recall 时，优先修复切片、候选生成和跨 crop 合并。
- 未达到逐类 P/R 双 0.90 前，不进入无人值守自动提报。
