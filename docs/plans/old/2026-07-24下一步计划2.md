## 1. Phase A：Stage 5 难负样本闭环（P0，本次训练核心）

### 1.1 执行流程

```text
Step 1: 难负样本采集
  python scripts/collect_hard_negatives.py \
      --model weights/stage4_best_finetune.pt \
      --data data/subway_crops \
      --output data/hard_negatives \
      --conf-threshold 0.3

Step 2: [可选] 快速人工抽查 (50张 FP crop)

Step 3: 混合数据 (正样本:难负样本 = 1:1)
  → 将 hard_negatives/ 下各子目录复制到 subway_crops/train/images/

Step 4: Stage 5 训练
  python scripts/train_pipeline.py --stages 5 \
      --model yolo11s-EMA-SimAM --device 0

Step 5: 阈值校准
  python scripts/calibrate_thresholds.py \
      --model weights/stage5_calibrated.pt \
      --data data/subway_crops
```

### 1.2 Stage 5 训练配置

沿用 `config/train/pretrain/stage5_hard_negative.yaml`：

| 参数 | 值 | 说明 |
|------|:--:|------|
| 初始化 | `stage4_best_finetune.pt` | 从 S4 best 继续 |
| epochs | 10 | 低 lr 微调，不宜过长 |
| lr0 | 1e-6 | 极低学习率，只学难负样本分布 |
| freeze | [0..9] | 冻结 backbone，只调 head |
| 增强 | 全关 | 只学真实分布 |
| amp | false | 低 lr 下避免精度损失 |
| batch | 4 | 小 batch 精细更新 |
| patience | 6 | 早停保护 |

### 1.3 完成门禁

- [ ] Stage 5 训练完成，无 NaN/OOM
- [ ] mAP50 ≥ 0.60（不低于 S4 的 0.622 的 96%）
- [ ] Precision ≥ 0.58（S4 基础上 +3pp）
- [ ] 阈值校准完成，输出 `thresholds.json`
- [ ] 逐类评估：无重点类 Recall 下降 >5pp

### 1.4 风险与应对

| 风险 | 应对 |
|------|------|
| 难负样本采集数量不足 | 降低 conf-threshold 至 0.2，扩大采集范围 |
| Stage 5 训练后 Recall 下降 | 调整正负比例（1:1 → 2:1），或降低 lr |
| amp=false 导致 VRAM 不足 | 降低 batch 至 2，或降低 imgsz 至 1024 |
