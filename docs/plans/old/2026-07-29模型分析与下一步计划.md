### 2.2 类别分级分析

#### 🟢 优秀组 (mAP50 > 0.80): DRPS, CBHPM, CBVPM

- **DRPS (0.992)**: 几乎完美的检测。吊弦不受力的视觉特征非常明显（线形断裂/变形），模型已完全学会。
- **CBHPM (0.880)** / **CBVPM (0.801)**: 销钉类缺陷特征明确（小孔/缺口），模型判别力强。CBVPM 的 Precision (0.584) 偏低，存在一定误检。

#### 🟡 中等组 (mAP50 0.50-0.57): SVHTNL, SVHBNL, BSBM, VHBNL

- **SVHTNL (0.572)**: Recall 高 (0.678) 但 Precision 低 (0.439)，存在较多误检。
- **SVHBNL (0.568)**: P/R 均衡 (0.499/0.584)，定位精度最好 (mAP50-95=0.486)，说明模型对此类的边界框回归较准。
- **BSBM (0.559)**: 危急类 (critical), 当前性能不足以支撑自动告警。P=0.593 意味着 40% 的告警是误报。
- **VHBNL (0.506)**: Recall 较高 (0.661) 但 Precision 偏低 (0.436)，"松动"与"正常"的视觉边界模糊。

#### 🟠 偏弱组 (mAP50 0.35-0.50): INSD, SVHBNM

- **INSD (0.463)**: Recall 极高 (0.873) 但 Precision 极低 (0.304) — 模型倾向于把各种纹理异常都判为绝缘子破损。需要针对性降低误检。
- **SVHBNM (0.388)**: Precision 尚可 (0.462) 但 Recall 低 (0.344) — 2/3 的真实缺失未被检出。可能存在标注不完全或特征不够明显的问题。

#### 🔴 极差组 (mAP50 < 0.25): VHBNM, RHTBNM, RHTBNL

- **VHBNM (0.229)**: 89 张图 93 个实例，样本量偏少。Recall 仅 0.214 — 78% 的缺失被漏检。
- **RHTBNM (0.162)** / **RHTBNL (0.103)**: 验证集仅 56/46 个实例，训练集仅 191/221 框。**数据量严重不足是根本原因**。模型几乎无法学习这两类的判别特征。

### 2.3 问题诊断矩阵

| 问题类型 | 涉及类别 | 表现 | 根因推测 |
|---------|---------|------|---------|
| **高 Recall 低 Precision** | INSD, SVHTNL | 检出多但误检也多 | 类别视觉特征不够特异，易与正常纹理混淆 |
| **低 Recall 尚可 Precision** | SVHBNM, VHBNM | 检出少但检出较准 | 标注覆盖不全 或 特征不明显 |
| **数据严重不足** | RHTBNM, RHTBNL | P/R 双低 | 训练集 < 250 框 |
| **松动 vs 正常难区分** | VHBNL, RHTBNL | 中等 Precision, 中等 Recall | 视觉差异极小，需要参考周围结构 |

### 3.3 Stage 5 效果分析

**正面发现：**
- **BSBM (+0.034)**: 唯一获得有意义提升的类别，P 和 mAP 双升。说明 BSBM 的 FP 模式与 HNM 样本匹配较好
- **SVHBNM (+0.023), INSD (+0.012)**: 微小改善
- **Overall Precision 提升显著 (+13.9%)**: 硬负样本有效降低了部分类别的误检率

**负面发现：**
- **SVHBNL (-0.120)**: 最大降幅。该类别的"松动"特征可能与 HNM 中的正常样本产生混淆，模型过度抑制
- **CBHPM Recall 骤降 (-0.301)**: Precision 提升但 Recall 暴跌，HNM 使模型过度保守
- **VHBNM Recall 归零**: Precision→1.0 但完全不再检出
- **整体 mAP 下降**: 9/12 类出现性能退化

**结论**: Stage 5 在当前数据集和配置下的成本（Recall 损失）超过了收益（Precision 提升）。**不推荐 Stage 5 作为默认部署模型**。如需降低特定类别的误检率，建议使用**推理端 per-class 阈值校准**（见第 5 节）替代 HNM 训练。

## 4. TTA (Test-Time Augmentation) 评估

### 4.1 测试配置

- 模型: Stage 4 best.pt
- 验证集: 3200 张, 1280px
- TTA 方式: Ultralytics 内置 `augment=True` (水平翻转 + 尺度放大)

### 4.2 结果

| 指标 | Standard | TTA | Δ |
|------|:-------:|:----:|:----:|
| mAP50 | **0.519** | 0.490 | **-5.6%** ❌ |
| mAP50-95 | **0.408** | 0.368 | **-9.8%** ❌ |
| Precision | **0.468** | 0.413 | -11.8% |
| Recall | 0.581 | 0.581 | 0% |
| 推理时间 | **12.4 ms** | 35.3 ms | +185% |

### 4.3 分析

TTA 在此任务上产生**全面负面效果**：

1. **Precision 大幅下降 (-11.8%)**: 翻转/缩放增强引入了更多低质量候选框，增加 FP
2. **Recall 持平**: 说明模型本身已能覆盖当前可检测目标，TTA 的增强预测未能发现新的 TP
3. **推理时间 2.85×**: 从 12.4ms 增至 35.3ms，对实时检测不友好
4. **高 IoU 退化更严重 (-9.8%)**: 增强预测的边界框融合降低了定位精度

**结论: 强烈不建议在此任务上使用 TTA。** 这与接触网缺陷检测的特性有关：缺陷方向具有固定的几何约束（水平/垂直），水平翻转会破坏方向信息。对于 CoordAtt 这类对方向敏感的注意力机制，翻转增强反而引入噪声。

- **DRPS 唯一**: auto_report Conf=0.529 → P=0.913, R=0.997。这是唯一无需改进即可满足验收标准的类别。

## 6. 难负样本扩充建议

### 6.1 当前 HNM 效果评估

基于 Stage 5 的结果分析，当前硬负样本挖掘效果有限。原因诊断：

1. **HNM 采集方式可能不匹配**: 当前 HNM 基于 Stage 4 模型在验证集上的误检收集。如果误检模式与实际部署场景不一致，HNM 训练无法有效降低目标域 FP。
2. **正负样本比例 1:1 过于激进**: 训练信号中一半是"这不是缺陷"，可能压制了正样本的学习。
3. **HNM 类型单一**: 主要集中在"类间混淆"（如正常螺栓 vs 缺陷螺栓），缺少"背景混淆"（如金属反光、阴影边缘）的多样性。

### 6.2 改进建议

#### 🔴 优先级 1: 从实际运营图像采集 HNM

当前 HNM 来自验证集，与真实部署分布可能有偏差。建议：

```
1. 使用 Stage 4 模型对全量原始大图 (655 张源图) 进行推理
2. 收集置信度 > 0.3 但 < 0.7 的检测框（"不确定"区间）
3. 人工标注确认是否为误检
4. 按类别和误检类型分类存储
```

#### 🟡 优先级 2: 调整 HNM 训练策略

```yaml
# 推荐配置变更
正负样本比例: 1:1 → 3:1 (降低 HNM 压制强度)
Stage 5 lr0:    1e-6 → 5e-6 (稍大学习率，更充分的 adaptation)
freeze:         [0-9] → [0-7] (减少冻结层数，neck 更深层参与学习)
epochs:         10 → 15 (更多迭代)
```

#### 🟢 优先级 3: 分类器级 HNM

对高 FP 类别 (INSD, SVHTNL, VHBNL) 训练专用二分类器:

```
Stage 4 模型 → 提取 INSD 误检 crops → 训练 INSD 专用二分类器
推理流程: S4 检测 → 对 INSD 类 → 二分类器二次验证 → 降低 FP
```

#### 🟢 优先级 4: 针对性数据增强

对 RHTBNM/RHTBNL 使用更强的 Copy-Paste 增强:

```bash
python scripts/generate_defect_copy_paste.py \
  --source data/subway_crops \
  --target-classes RHTBNM RHTBNL \
  --paste-prob 0.5 --max-pastes 5 \
  --min-bbox-size 40 --max-bbox-size 180
```

### 6.3 可行 HNM 来源 (按优先级)

| 来源 | 数量估计 | 采集难度 | 效果预期 |
|------|:------:|:------:|:------:|
| 当前 train set FP | ~500-1000 | 低 (已有) | 中 |
| 655 张源图推理 FP | ~2000-5000 | 中 | **高** |
