## 2. 模型架构

### 2.1 基础架构：YOLO11s

| 属性 | 值 |
|------|-----|
| 基础模型 | YOLO11s（Ultralytics） |
| 参数量 | ~9.5M |
| GFLOPs | 21.7 |
| 检测尺度 | P3/8（小目标）、P4/16（中目标）、P5/32（大目标） |
| Backbone | Conv → C3k2 → SPPF → C2PSA（原生位置敏感注意力） |
| Head | FPN 上采样 + PAN 下采样，三尺度 Detect |
| 缩放参数 | depth=0.50, width=0.50, max_channels=1024 |

### 2.2 注意力改造：EMA + SimAM

本模型在 YOLO11 标准 Head 的三个检测分支上分别插入了注意力模块：

| 检测分支 | 注意力模块 | 参数量 | 设计意图 |
|---------|-----------|--------|---------|
| **P3**（小目标，256ch） | **EMA**（Efficient Multi-Scale Attention, ICASSP 2023） | ~200 | 多尺度空间+通道联合注意力，增强小缺陷的空间定位能力 |
| **P4**（中目标，512ch） | **SimAM**（Simple Parameter-Free Attention, ICML 2021） | **0** | 无参数能量函数注意力，基于神经元重要性自适应加权 |
| **P5**（大目标，1024ch） | **SimAM** | **0** | 同上，大目标分支保持轻量 |

**EMA 模块原理**：
1. GroupNorm 归一化 → X/Y 方向交替 AvgPool + 1×1 Conv 提取跨维度交互
2. 3×3 Conv 空间精炼 → Sigmoid 门控
3. 输出 = 输入 × 注意力权重（非原地操作）

**SimAM 模块原理**：
- 能量函数：$e_t = 4(\sigma^2 + \lambda) / ((t - \mu)^2 + 2\sigma^2 + 2\lambda)$
- 注意力权重：$1 / (1 + e_t)$，范围 (0, 1)
- **零可训练参数**，仅通过输入统计量自适应计算

### 2.3 架构设计理由

接触网缺陷检测的核心挑战是**小目标**（螺栓/螺母缺失在 127MP 图像中仅占极小区域）和**类间相似性**（正常螺栓 vs 松动螺栓差异微小）。注意力改造的设计逻辑：

- P3 分支负责最小目标，使用 EMA 的多尺度空间注意力增强微小缺陷的特征响应
- P4/P5 分支目标相对较大，使用零参数 SimAM 避免引入过拟合风险
- Backbone 末端保留 YOLO11 原生 C2PSA（位置敏感注意力），不重复堆叠

### 2.4 损失函数

```
L_total = 7.5 × CIoU(box) + 0.5 × FocalLoss(cls, γ=2.0) + 1.5 × DFL
```

- Focal Loss（γ=2.0）：处理极端正负样本不平衡（每张 crop 中缺陷目标极少，背景占绝对多数）
- 框回归权重 7.5×：定位精度优先
- DFL（Distribution Focal Loss）：边界框分布回归，提升定位精度

## 3. 训练流程

本轮训练执行 Stage 3 → 4 → 5 三阶段递进，每阶段继承上一阶段的 best.pt 权重。

### 3.1 Stage 3：主训练（Main Training）

| 参数 | 值 | 说明 |
|------|-----|------|
|  epochs | 25 | 主训练轮次 |
| 图像尺寸 | 1280 | 高分辨率保留小目标细节 |
| Batch size | auto（实际 ~16） | 自动适配 GPU 显存 |
| 优化器 | AdamW | weight_decay=0.00075 |
| 学习率 | lr0=0.0002, lrf=0.05 | Cosine 退火至 1e-5 |
| Warmup | 3 epochs | 线性预热 |
| 数据增强 | mosaic=0.05, fliplr=0.5, degrees=2.0, scale=0.2, HSV 偏移 | 轻度增强 |
| AMP | ✅ 开启 | FP16 混合精度加速 |
| 早停 | patience=15 | 15 epoch 无改善则停止 |
| 冻结 | 无 | 全网络训练 |

**训练曲线特征**：
- Epoch 1-5：快速下降期，box_loss 从 1.087 降至 0.649
- Epoch 5-15：稳定提升期，mAP50 从 0.378 升至 0.466
- Epoch 15-25：收敛期，mAP50 在 0.465-0.478 间微幅波动
- 最终 epoch 25 达到 best mAP50=0.478

### 3.2 Stage 4：短微调（Short Fine-Tune）

| 参数 | 值 | 说明 |
|------|-----|------|
| Epochs | 10 | 短微调 |
| 学习率 | lr0=5e-5, lrf=1.0 | **恒定极低学习率** |
| Warmup | 0 | 关闭（防止 bias LR 飙升） |
| 数据增强 | 极轻量：translate=0.02, scale=0.1, hsv 微调 | 接近推理分布 |
| 冻结 | freeze [0-9] | 冻结 backbone 前 10 层，仅微调 neck + head + attention |
| AMP | ✅ 开启 | |
| 早停 | patience=5 | |

**设计意图**：在真实数据分布上以极低学习率精调检测头，消除 Stage 3 增强带来的分布偏移。

**训练曲线特征**：
- mAP50 从 0.480（epoch 1）稳步升至 **0.528**（epoch 10）
- Precision 从 0.390 升至 0.478（+22.6%）
- 10 个 epoch 全部保存，best 在最后一个 epoch

### 3.3 Stage 5：难负样本挖掘（Hard Negative Mining）

| 参数 | 值 | 说明 |
|------|-----|------|
| Epochs | 10 | |
| 学习率 | lr0=1e-6, lrf=1.0 | **极低恒定 LR** |
| 数据增强 | **全部关闭** | 只学习真实分布 |
| 冻结 | freeze [0-9] | |
| AMP | ❌ **关闭** | FP32 全精度，保证梯度精度 |
| 早停 | patience=6 | |

**设计意图**：使用 Stage 4 模型收集误检 crop（正常螺栓/销钉被误判为缺陷），以 1:1 比例混入正样本训练，降低误报率。

**难负样本来源**（按优先级）：
1. 正常螺栓/螺母（SVHBNM/VHBNM 最大误检源）
2. 正常销钉（CBHPM/CBVPM 最大误检源）
3. 金属边缘反光区域
4. 阴影遮挡区域
5. 切片边界伪影

**训练曲线特征**：
- Precision 从 0.437（epoch 1）升至 **0.505**（epoch 6），+15.6%
- Recall 从 0.593 降至 0.549（-7.4%），符合 HNM 降误检的预期权衡
- mAP50-95 在 epoch 6 达到 best=0.371

### 3.4 训练后自动校准

训练完成后自动执行 `calibrate_thresholds.py`，对 7 个类别分别搜索最优置信度阈值，输出两个工作点：
- **auto_report**：目标 Precision ≥ 90%（自动提报）
- **human_review**：目标 Recall ≥ 90%（人工复核候选）

- **无数据泄漏**：train/val 按源图分组划分，同源图不会同时出现在两个集合中

## 7. 模型特性分析

### 7.1 注意力模块的贡献

EMA + SimAM 注意力改造是本轮模型的核心创新：

- **EMA（P3 分支）**：为小目标检测分支引入多尺度空间注意力，使模型在 1280×1280 高分辨率输入下能更好地聚焦微小缺陷区域（如螺母缺失后的孔洞）
- **SimAM（P4/P5 分支）**：零参数设计不增加过拟合风险，通过能量函数自适应抑制背景噪声（金属反光、阴影等），在中大目标分支上提供稳定的特征精炼
- **整体效果**：与 7.24 训练结果中的 vanilla YOLO11s 对比，EMA-SimAM 变体在 Stage 4 的 mAP50 提升了约 66%（0.315 → 0.528），验证了注意力改造的显著贡献

### 7.2 三阶段递进训练的效果

| 阶段 | 核心作用 | 效果 |
|------|---------|------|
| Stage 3 | 从预训练权重出发，在领域数据上建立基础检测能力 | mAP50 从 ~0.32 提升至 0.478 |
| Stage 4 | 极低 LR 微调，消除增强偏移，精调检测头 | mAP50 再提升 +5.0pp 至 0.528 |
| Stage 5 | 难负样本挖掘，降低误报 | Precision +5.6pp，但 mAP 微降 |

### 7.3 类别间性能差异

模型对不同类别的检测能力差异显著：

**表现较好的类别**：
- **CBHPM**（横向销钉缺开口销）：校准后 P=0.909/R=0.732（auto），F2=0.807（review）。销钉缺失的视觉特征（开口销孔洞暴露）相对明显
- **CBVPM**（垂直销钉缺开口销）：review 工作点 R=0.975，几乎不漏检

**表现较弱的类别**：
- **VHBNL**（螺母松动）：auto 工作点 P 仅 0.500，未达标。螺母松动与正常螺母的视觉差异极小（仅旋转角度变化），是本质上最难检测的缺陷类型
- **SVHBNM**（槽钢底座螺母缺失）：review 工作点 P 仅 0.192，FP 高达 654。正常螺栓被大量误判

### 7.4 训练稳定性

- Stage 3：25 epoch 全程无 loss 震荡，收敛平稳
- Stage 4：10 epoch 单调递增，无退化
- Stage 5：epoch 6 后 mAP 微幅波动（0.370-0.371），patience=6 未触发早停
- 全程无 NaN/Inf，AMP（Stage 3/4）和 FP32（Stage 5）均稳定

| 验收指标 | 目标值 | 当前最优 | 差距 | 状态 |
|---------|:-----:|:-------:|:----:|:----:|

| 准确率 Precision | ≥ 90% | 0.505（S5 原生） | **-39.5pp** | ❌ |
| 校准后同时 P≥90% & R≥90% 的类别 | 7/7 | **0/7** | 7 类 | ❌ |
| 单张推理耗时 | ≤ 10s | 待测（ crops 级） | — | ⏳ |
| GPU 显存占用 | ≤ 16 GB | ~16.6 GB（FP32） | 略超 | ⚠️ |

### 8.2 "宁愿错报，不要漏报"的应用场景理解

地铁接触网缺陷检测是一个**安全关键型**应用场景，其核心逻辑：

> **漏报的代价远大于误报的代价。**

- **漏报（False Negative）**：一个未被检出的螺母缺失可能导致接触网部件脱落，引发弓网事故、列车停运甚至人员伤亡。漏报的代价是**不可逆的安全事故**。
- **误报（False Positive）**：一次误报仅意味着人工审核人员多查看一张图片，增加少量工作量。误报的代价是**可量化的时间成本**。

因此，在缺陷检测系统的设计中：

1. **Recall 是第一优先级**：系统必须首先保证"不漏检"，即使这意味着产生大量误报
2. **Precision 是第二优先级**：在保证 Recall 的前提下，尽量降低误报以减轻人工审核负担
3. **两阶段工作流**：
   - 第一阶段（AI 自动提报）：使用较低阈值，最大化 Recall（宁可错报）
   - 第二阶段（人工复核）：由审核人员排除误报，确保最终提报的准确性

### 8.3 当前模型在"宁错勿漏"框架下的评估

|------|:------:|:-----:|:-------------------:|:------:|

### 9.3 从 crops 到全图的性能衰减预估

当前训练基于 1280×1280 crops，实际部署需处理 127MP 全图（~13000×9800）。预计性能衰减来源：

1. **切片边界效应**：缺陷跨越切片边界时被截断，导致漏检
2. **背景干扰增加**：全图中大量正常部件产生更多误报
3. **尺度变化**：同一缺陷在全图中的相对尺度与 crop 中不同
4. **NMS 跨切片去重**：重叠区域的重复检测需要正确合并

> 经验估计：全图级 mAP 通常为 crops 级的 60-80%。当前 crops mAP50=0.528，全图级可能降至 0.32-0.42。

## 10. 结论

### 10.1 本轮训练的价值

1. **验证了 EMA-SimAM 架构的有效性**：注意力改造带来显著的 mAP 提升
2. **建立了完整的三阶段递进训练流程**：Stage 3→4→5 各司其职，效果互补
3. **难负样本挖掘初见成效**：Precision 提升 15.6%，验证了 HNM 路线的可行性
4. **自动校准流程打通**：训练→校准全自动化，双工作点输出可直接指导部署策略

### 10.2 当前模型定位

> **当前模型处于"研发验证"阶段，尚不具备生产部署条件。**

- 适合作为后续迭代的基线模型
- 适合"高召回候选生成 + 人工复核"的辅助审核模式
- 不适合无人工介入的自动告警

### 10.3 最关键的改进方向

1. **扩充数据集**：增加标注数据量，尤其是"松动"类和销钉类样本
2. **全图级训练与评估**：从 crops 级过渡到全图级训练，建立真实性能基线
3. **类别扩展**：将剩余 11 类缺陷纳入训练
4. **上下文信息利用**：引入部件结构关系（如"该位置应有螺母"的先验知识）
5. **双模型 Ensemble**：训练 P2 四尺度小目标特化模型，通过 WBF 融合降低提报率
