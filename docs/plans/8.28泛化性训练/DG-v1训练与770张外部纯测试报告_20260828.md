# DG-v1 训练、特征诊断与 770 张外部纯测试报告

日期：2026-08-28  
实验名称：DG-v1（Domain Generalization v1）  
结论等级：**不通过，不建议部署**

## 1. 结论摘要

DG-v1 在训练数据同域的 551 张内部测试集上仍有较高指标：Precision 94.34%、Recall 87.89%、mAP50 96.17%、mAP50-95 75.63%。但在 770 张接近实际线路环境的外部数据上，按置信度 0.25、IoU 0.5、全部 16 个模型类别统计，仅得到：

- TP = 1，FP = 2840，FN = 813；
- Precision = 0.0352%，Recall = 0.1229%，F1 = 0.0547%；
- 770 张中有 733 张出现检测框，只有 37 张无检测框；
- 814 个真实框中只正确匹配 1 个，外部迁移能力不满足使用要求。

与原 Stage4 权重相比，DG-v1 的真阳性由 0 增至 1，但误报由 2071 增至 2840（增加 769 个，+37.13%）。因此，DG-v1 不能被判定为“提升成功”。外部 AP 数值虽有倍数增长，但绝对值仍接近零，且误报显著恶化。

纯测试前后 `best.pt` 的 SHA-256 均为 `42e5964636a9b377d090a09091d93638caae4baf966d64a1a9d9f834e88ac3a3`。770 张图片没有参与梯度更新、损失计算或最佳权重选择，测试过程没有改变模型。

## 2. 数据边界与实验目的

### 2.1 数据集 2：训练域

- 训练目录共 7781 张，其中 5211 张为离线重复增强图。
- DG-v1 只使用 2570 张原始基础图进行训练，避免把相同背景的离线增强副本重复采样。
- 验证集 551 张，独立内部测试集 551 张。
- 模型定义为 16 类，但类别 7、8、9、10 在训练、验证和内部测试中均无正样本。

### 2.2 数据集 1：实际场景域

- 770 张图片、814 个真实框。
- 有真实框的类别为：CBHPM 204、CBVPM 207、RHTBNM 67、RHTBNL 51、INSD 216、DRPS 69。
- 其中 RHTBNM 与 RHTBNL 共 118 个真实目标，对应训练数据中零正样本类别，因此模型无法从本轮训练中学到这两类的视觉表达。

### 2.3 防止数据泄漏的边界

770 张实际场景图片只用于固定的特征探针和最终推理，不进入训练损失，不参与 checkpoint 选择。由于旧模型失败分析和域差异分析已经参考过这 770 张，本次结果属于**自适应外部基准**，不再是完全盲测。后续若要给出部署结论，必须另建从未参与设计的新线路盲测集。

低层像素特征的域分类器在平衡采样下达到 balanced accuracy 0.9978、AUC 1.000；即使将训练图做灰度/亮度增强后，与实际域区分的 balanced accuracy 仍约 0.998、AUC 约 0.996。说明差异并非简单的“彩色变灰”或“整体变暗”，还包含成像响应、构图、局部对比度、规则设施背景和目标上下文的联合变化。

实际目标并不比训练协议下的目标更小：训练协议换算后的真实框短边中位数约 99 px，实际 1280 滑窗推理中的短边中位数约 193.5 px。因此，本次失败不能主要归因于“小目标分辨率不足”。

## 4. DG-v1 的修改内容

DG-v1 从旧 Stage4 `best.pt` 初始化，保持 16 类、四检测头结构，不改推理图结构，主要修改训练过程：

1. 全量解冻，不再冻结 backbone 0–9 层。
2. 在第 2、5 层加入仅训练时生效的 MixStyle，`p=0.5`、`alpha=0.1`，扰动批内通道统计。
3. 在线传感器域增强：灰度概率 0.6，并加入 gamma、亮度/对比度、噪声和模糊变化。
4. 以 0.5 概率执行保留真实框的方形裁剪，裁剪尺度 0.55–0.95，并同步更新框坐标。
5. 只采样 2570 张基础原图，配合轻度几何增强，降低离线增强副本造成的背景记忆。
6. 使用类别频率平方根倒数权重；无训练样本的 7–10 类只能置极小权重 0.001，权重调整不能凭空创造类别特征。
7. 在层 2、5、8、11、22、26、30、34，于 epoch 0、1、5、10、20、30、40 记录域线性探针、激活富集、反事实相似度和热图。

主要训练参数：40 epochs、imgsz 1280、batch 8、AdamW、初始学习率 `5e-5`、cosine LR、warmup 2 epochs、weight decay `7.5e-4`、AMP、seed 42。训练耗时约 5431.56 秒（90.53 分钟），GPU 峰值显存约 17.7 GB，无 OOM 或 NaN。

## 7. 模型内部特征诊断

### 7.1 域线性探针

epoch 0 的八个探针层域 AUC 均为 1.000。epoch 5 时层 5 降至 0.9625、层 11 降至 0.975，其余层仍为 1.000；epoch 10、20、30、40 的全部探针层又均为 1.000。

这意味着一个简单线性分类器仍可以从各层激活中完全区分训练域和实际域。MixStyle 与传感器增强短暂降低了少数浅层的可分性，但没有形成持续的域不变表示。AUC 是诊断指标，不等于因果证明，不过它与外部测试几乎归零的结果一致。

### 7.2 目标激活富集

实际域在检测层 22、26、30、34 的目标/背景激活富集值：

| 层 | epoch 0 | epoch 40 | 变化 |
|---|---:|---:|---:|
| 22 | 1.374 | 1.245 | 降低 |
| 26 | 1.382 | 1.287 | 降低 |
| 30 | 1.354 | 1.197 | 降低 |
| 34 | 1.516 | 1.179 | 降低 |

训练域 epoch 40 的对应值仍约为 2.300、2.320、2.227、2.500。即模型在训练域内仍能让目标区域明显高于背景，而实际域的目标响应只略高于背景，并且相对初始化权重进一步下降。反事实余弦相似度略升只能说明部分风格扰动前后的特征更相似，不能抵消域 AUC=1.000 与目标富集下降的证据。

## 8. 误报、漏报和错报的主要原因

1. **传感器与成像域断裂。** 训练域偏亮、彩色、纹理丰富，实际域偏暗、近灰度、低局部对比度。简单颜色和亮度增强没有覆盖真实相机的响应、噪声与动态范围。
2. **目标与局部背景对比度崩塌。** 中位亮度差从 33.71 降至 3.50，模型在实际域难以把缺陷从设备本体中分离，造成 813 个漏报。
3. **规则设施背景被当作缺陷。** 绝缘子、线缆、夹具、杆件、反光边缘和交叉结构产生稳定高频形状，模型把训练域中与类别共现的结构捷径迁移成 GWCNL、INSD、CBHPM 等误报。
4. **训练背景多样性不足。** 离线增强虽增加图片数量，但 5211 张副本仍重复相同实训中心背景。DG-v1 改用基础图只能减少重复，不能补充真实线路的负背景分布。
5. **缺失类别无法通过重加权补齐。** 类别 7–10 零正样本，其中实际测试正好含 118 个 RHT 类目标；模型没有监督信号学习这些类别。
6. **构图和上下文不一致。** 训练多为 4:3 全图/letterbox，实际为方形成像并采用原生 1280 滑窗。方形裁剪只修正了一部分几何差异，没有构造足够多的实际设备上下文。
7. **旧模型和注意力结构已形成背景捷径。** DG-v1 从旧 Stage4 初始化；全量解冻和 40 个 epoch 未能彻底改变已有决策边界。多尺度/浅层高分辨率分支可能放大规则细线和高光，但实际目标并不小，因此不能简单归因于 P2 检测头，必须做有控制的消融。
8. **同域验证指标掩盖域外失败。** 验证/测试图片与训练域共享采集地点、设备风格和背景规律，高 mAP 主要证明同分布拟合，不能证明线路迁移能力。
9. **阈值不是根因。** 唯一 TP 与其余误报都集中在约 0.25 附近；提高阈值会同时删除唯一 TP，降低阈值则增加更多误报。在模型还没有召回能力前，调置信度不能解决问题。

## 9. DG-v1 验收判定

- 同域性能保持：通过；
- 域特征不可分性：不通过，epoch 40 各层域 AUC 仍为 1.000；
- 外部召回：不通过，仅 0.1229%；
- 外部精度：不通过，仅 0.0352%；
- 误报控制：不通过，FP 比旧权重增加 37.13%；
- 部署资格：不通过。

因此保留 DG-v1 权重和全部结果作为失败实验基线，不覆盖旧权重，不投入实际检测。

## 10. 下一轮 DG-v2 建议

建议先冻结评价协议，再做单变量消融：

1. 先划出新的、未参与任何方案设计的线路盲测集；现有 770 张拆出适配/硬负样本挖掘集，但不再充当最终盲测。
2. 补采并标注类别 7–10，尤其 RHTBNM/RHTBNL；在补齐前，16 类模型的完整召回目标不可达。
3. 按实际推理方式生成原生 1280 方形训练 tile，保留目标与真实上下文尺度；用目标保留裁剪作为补充，而非主要几何模拟。
4. 从适配集挖掘 INSD、GWCNL、CBHPM、DRPS 的高置信硬负样本，加入“无缺陷真实线路背景”训练，直接惩罚规则结构误报。
5. 将真实缺陷目标做边界约束的实例粘贴/融合，放入多样化线路负背景；同时保留一部分原始目标上下文，避免只学粘贴边缘。
6. 对浅层网络做 IBN/InstanceNorm 消融，或增加梯度反转域对抗头；把域探针 AUC 作为诊断门槛，例如目标先降至 0.8 以下，但最终仍以盲测检测指标为准。
7. 增加目标裁剪的监督式对比学习或目标/背景分离分支，要求同类别跨成像域接近、规则背景远离类别中心。
8. 对 P2/四检测头做受控消融：在完全相同的数据和 seed 下比较四头、三头以及浅层门控，观察召回与每图 FP；不能因为当前误报多就直接删除 P2。
9. 在盲测上同时报告全部 16 类的 TP/FP/FN、每图 FP、每类 AP、无目标图误报率和置信区间。只有先获得有效召回后，才做阈值和温度校准。
