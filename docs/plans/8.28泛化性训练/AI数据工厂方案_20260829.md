用与上一份报告相同的探针流程实测（`scripts/probe_normal_dataset_domain_20260829.py`）：

### 1.3 它能撑起多大训练量

## 2. 对"缺陷零件移植"方案的技术评估

### 2.1 三个坑

**坑 1：粘贴边界会成为新的捷径。** DG-v1 报告自己就写过"避免只学粘贴边缘"。GrabCut 在金属件上表现尤其差——金属反光、细杆件、螺栓边缘都是它的失效区。模型很容易学到"边缘有融合痕迹的地方 = 缺陷"。

**坑 2：光照/透视/姿态三重不一致。** 车间零件是近距离、单侧 LED 打光、特定角度；现场图里同一部件是远距离、隧道补光、不同视角。硬贴上去，即使 Poisson blending 也救不回透视和姿态。

**坑 3（最关键）：本项目绝大多数缺陷是"状态的缺失或位移"，不是"多了一个东西"。**

| 缺陷语义 | 物理表现 | 能靠"移植零件"造出来吗 |
|---|---|---|
| 螺母**缺失**（VHBNM/SVHBNM/GWCNM/RHTBNM/BSBM） | 该有螺母的地方**没有** | ❌ 移植是"加"，缺失是"减" |
| 销钉**缺开口销**（CBHPM/CBVPM） | 少一根开口销 | ❌ 同上 |
| 螺母**松动**（VHBNL/SVHBNL/SVHTNL/GWCNL/RHTBNL） | 螺母位移几像素 / 双螺母间隙变化 / 露出螺纹 | ❌ 这是"微扰"不是"替换" |
| 绝缘子**破损**（INSD） | 伞裙缺损、裂纹 | ⚠️ 可以，但要局部重绘 |
| 吊弦**不受力**（DRPS） | 吊弦松弛下垂 | ⚠️ 可以，几何形变 |

16 类里**至少 9 类无法用"移植零件"生成**。

### 2.2 关键改向：编辑状态，而不是移植零件

> **不要"把车间的缺陷零件搬到现场图上"，而要"在现场的正常工作部件上，把它的状态改成缺陷"。**

好处：
- 背景 100% 来自目标域，无跨域移植问题；
- 光照、透视、材质天然一致；
- 缺陷的"上下文"（相邻的正常部件、支架、隧道壁）是真实的——这正是模型最缺的负上下文；
- 标注框自动对齐（编辑发生在哪个部件上，框就在哪里）。

三种编辑原语：

| 原语 | 适用类别 | 技术手段 |
|---|---|---|
| **删除**（对应"缺失"） | VHBNM, SVHBNM, GWCNM, RHTBNM, BSBM, CBHPM, CBVPM | SAM 3 分割部件 → mask 内 inpainting 擦除 → 补绘螺栓/孔洞/积尘 |
| **微扰**（对应"松动"） | VHBNL, SVHBNL, SVHTNL, GWCNL, RHTBNL | 分割螺母 → 沿轴向平移 / 小角度旋转 / 加间隙 → Poisson seamlessClone 融合 |
| **局部重绘**（对应"破损/不受力"） | INSD, DRPS | 参考图引导的 mask 内重绘 |

### 2.3 微扰参数不能拍脑袋，要从真实样本标定

"松动"到底位移几像素，不能靠感觉。做法：

1. `train_data_2` 里有真实松动样本（VHBNL 1660、SVHBNL 771、SVHTNL 708）；
2. 用配准/关键点方法对齐"正常"与"松动"样本，估计真实的位移场与形变模式；
3. 统计得到经验分布（轴向位移 px、旋转角度、螺纹露出长度、双螺母间隙宽度）；
4. 合成时**从这个经验分布采样**，而不是用固定值。

这一步是"合成像不像"的分水岭。

### 2.4 一个必须防的陷阱：inpainting 过度完美

用 inpainting 擦除螺母后，模型看到的可能不是"这里少了螺母"，而是"这里很平滑"——它会学到"平滑 = 缺陷"，这是另一种捷径。

对策：
- 擦除后**必须补绘缺陷痕迹**：露出的螺栓杆、螺纹、孔洞阴影、积尘边界、金属氧化色差；
- 用**参考引导**而非纯 inpainting：给模型看一张真实的"螺母缺失"样本作为参考；
- 保留一部分"部分遮挡"的真实样本作为对照，防止模型只认平滑区域。

## 3. AI 数据工厂：五层架构

不是"用 AI 替代 PS"，而是把数据生产变成一条**可控、可质检、可扩量**的流水线。

```
L1 底图获取  →  L2 部件结构化  →  L3 状态编辑  →  L4 质量门禁  →  L5 主动学习闭环
   （零/低成本）    （AI 自动）      （AI+程序化）   （Agent 质检）   （省标注预算）
```

### L1　底图获取（成本最低，优先做满）

| 来源 | 规模 | 成本 | 状态 |
|---|---|---|---|
| `data/Normal_dataset` | 921 张可用 | 0 | **现成，未用** |
| 车载日常作业回流原始大图 | 每天数百–数千张 | 极低（车本来就在跑） | 需建回流通道 |
| 场段（车辆段/停车场）专项拍摄 | 可控 | 低 | 需协调，见 §5 |
| 770 张中 GT=0 的 199 张 | 199 张 | 0 | 需在 LOSO-CV 中按折使用 |

**车载回流是被严重低估的资源**：正线不允许有缺陷，但检测车天天在跑，能拍到**海量的正常部件**——而这正是解决 P(缺陷|部件) 错位最需要的东西。回流数据**不需要标注**，只需按 §4 的门禁自动筛掉可疑区域。

### L2　部件结构化（AI 自动，人工只抽检）

用 **SAM 3**（Meta，2025-11 发布 / SAM 3.1 于 2026-03）的两种提示模式：

- **Exemplar prompt（本项目最合适）**：给一个"绝缘子"的样例框（从已标注数据里取），SAM 3 自动找出图中**所有**同类实例并给出精确 mask；
- **Text prompt**：开放词汇短名词短语，如 "insulator"、"cable clamp"、"hex nut"、"split pin"。

产出：**现场正常部件实例库**——数万个实例，全部来自目标域，带 mask + bbox + 部件类型。

人工只做 **5–10% 抽检**，主要看 mask 边界质量。

> 这一步把"人工在 PS 里框选部件"这个最耗时的环节自动化了，是整个方案提效最大的一环。

### L3　状态编辑（三条通道，按可靠性排序）

**通道 A：程序化编辑（确定性、无幻觉，优先做）**
- 缺失类：SAM 3 mask → 先进 inpainting 擦除（LaMa / MAT；复杂结构用 Qwen-Image-Edit-2511 的 mask 模式）→ 补绘螺栓/孔洞/积尘
- 松动类：从 §2.3 的经验分布采样位移/旋转/间隙 → 几何变换 → `cv2.seamlessClone` → 局部阴影重绘
- 标注自动产生，100% 准确

**通道 B：参考引导编辑（用于破损/不受力类）**
- 输入：现场正常部件图 + 车间同类缺陷图（作为参考）+ 部件 mask
- 模型在 mask 内重绘为缺陷状态，mask 外**严格不变**
- 候选模型（均为 Apache 2.0，可商用）：**Qwen-Image-Edit-2511 / Qwen-Image-2.0**、**FLUX.2-klein-4B**；备选 LongCat-Image-Edit、FireRed-Image-Edit-1.1（身份一致性更强）
- ⚠️ **不要用 FLUX.1 Kontext [dev]**——权重是非商用许可，本项目是商业交付

**通道 C：光照一致性后处理（消除"粘贴感"的关键）**
- 局部直方图匹配到周围 patch
- **IC-Light** 或类似重打光方法：让编辑区域的光照方向与强度与场景一致
- 在编辑边界环带做梯度平滑

### L4　质量门禁（Agent 自动质检 —— 决定成败的一环）

合成数据项目大多死在这一步。必须建立**量化门禁**：

| 门禁 | 方法 | 阈值 |
|---|---|---|
| **真伪判别器** | 训练小分类头区分"真实拍摄 / AI 合成" | balanced acc **> 70% 即打回**（说明伪影明显） |
| **可检出性自检** | 用当前模型跑合成图，缺陷框必须被检出 | 置信度 **< 0.5 即打回**（说明合成得太弱/不像） |
| **边界伪影检测** | 在粘贴边界环带计算梯度异常 | 超过真实图统计的 p95 即打回 |
| **分布一致性** | 合成图与真实图在 §1.2 的 36 维特征上的域探针 | acc **> 0.95 即打回** |
| **人工抽检** | 每批 5%，双人 | 合格率 **< 90% 整批复检** |

### L5　主动学习闭环（把 PS 预算压到刀刃上）

人工 PS 不该被"替代"，而该被"节约"——只用在模型最需要的地方：

1. 用当前模型在回流数据上推理；
2. 挑**高不确定性**样本（预测熵最高 / 多模型预测不一致 / 置信度落在 0.3–0.6 区间的）；
3. 用 SAM 3 + 当前模型做**预标注**，人工只做修正；
4. 只把这批送人工 PS/复核。

文献与工业实践的经验值是**标注效率提升 3–5 倍**。对本项目的意义：PS 预算不变的情况下，有效样本量翻数倍；或者样本量不变，成本降到 1/3–1/5。

### Agent 在其中做什么

不是"用 Agent 生成图片"，而是让 Agent 承担**编排与质检**：

- **编排**：调度 L1→L5，管理任务队列、失败重试、版本与哈希留痕（沿用项目已有的 Material Passport 规范）；
- **质检**：L4 的五个门禁全部自动化，不合格自动打回并调整参数重试；
- **自适应**：哪一类样本模型表现最差，自动提高该类的合成配额；
- **审计**：每批合成数据自动生成统计报告（类别分布、尺度分布、光照分布、门禁通过率），可追溯。

## 5. 不是 AI，但性价比更高的两条路

AI 合成再好也是"造"的。有两条路能拿到**真的**数据，且成本远低于人工 PS：

### 5.1 场段（车辆段/停车场）专项拍摄

正线不能设缺，但**车辆段、停车场、试车线的接触网可以**——不载客、不影响运营、天窗期可作业。这些地方的接触网设备与正线同型号，成像条件接近。

改进计划 §表 3-2 已经写了这条路（"与业主协调安排场段专项拍摄"），但看起来没有真正推进。**这应该优先于所有 AI 合成方案去争取。**

### 5.2 可拆卸缺陷模拟件

行业通行做法：制作一套**可快速装拆的缺陷模拟件**（松动的螺母副、缺开口销的销钉、破损绝缘子伞裙的贴片等），在真实接触网上临时安装、拍摄、拆除，全程几分钟。

- 拍摄背景 100% 真实，成像链路 100% 真实；
- 单件成本远低于 PS 人工；
- 一套模拟件可反复使用，边际成本递减；
- 还能顺带拍到"安装/拆卸过程"的成对图像，正好用来标定 §2.3 的"松动位移分布"。

### 5.3 与 AI 方案的关系

```
场段拍摄 + 模拟件     →  提供"真的"缺陷样本（少量但高质量）
        ↓ 用来标定
AI 状态编辑           →  在海量现场正常图上批量复制这些缺陷模式
        ↓
主动学习闭环          →  决定下一批真实拍摄/模拟件该拍什么
```

**真实样本负责"定义缺陷长什么样"，AI 负责"把它规模化"。两者是互补关系，不是替代关系。**

## 8. 风险与止损

| 风险 | 等级 | 应对 |
|---|---|---|
| 合成数据引入新捷径（模型学"合成伪影"而非缺陷） | **高** | L4 门禁是硬门槛，不是可选项。真伪判别器 acc > 70% 一律打回 |
| 21k 个无缺陷 tile 让模型变得过度保守，召回下降 | **中** | 分档实验（24% / 50% / 100%），用 LOSO-CV 找拐点，**不要一次加满** |
| Normal 与测试集存在 0.88 的域残差 | 中 | 区段分层采样；最终必须用留一区段 CV 验证，不能看同域 mAP |
| SAM 3 在金属反光/细杆件上分割失败 | 中 | 人工抽检 5–10%；失败样本降级用 bbox 粗 mask + 羽化 |
| inpainting 过度完美（见 §2.4） | 中 | 必须补绘缺陷痕迹；用真实缺失样本做参考引导 |
| 场段拍摄申请不下来 | 中 | 退守模拟件方案（成本更低）；AI 合成提权 |
| 商用许可风险 | **高** | 只用 Apache 2.0 / SAM License；**禁用 FLUX.1 Kontext [dev]** |
| 合成数据参与 checkpoint 选择导致指标虚高 | **中** | **合成数据只进训练集，绝不进 val/test**；checkpoint 选择只用真实数据 val |
