# 离线像素域对齐可行性实测报告

日期：2026-08-29
问题：用离线手段把 `Defect_dataset_2`（车间）的图片参数改到贴近旧 `Defect_dataset`（检测车实拍），是否可行？预期效果如何？

**结论先行：技术上可行，但只能买到约 0.5 个百分点的域可分性改善——接近于零。逐特征看对齐率中位数高达 97%，但两域在联合分布上仍然几乎完全可分。这条路不值得单独投入，它正确的位置是混合域训练的辅助增强，而不是替代品。**

---

## 1. 实测设计

本地恰好同时拥有两组数据，可以直接做真值对照实验：

| 用途 | 数据 | 数量 |
|---|---|---:|
| 源域（车间） | `data/Defect_dataset_2/Defect_dataset/images/` | 抽 300 张 |
| 目标域（检测车实拍） | `data/Defect_dataset/images/`（其中 500 张就在那 770 张里） | 抽 400 张 |

步骤：

1. 两边统一 **square-crop + resize 到 640×640**，消除几何差异，只留像素风格差异；
2. 用**同一套** 36 维低阶特征（亮度统计、暗/亮像素占比、饱和度、色彩丰富度、边缘密度、梯度、Laplacian 方差、熵、FFT 高频比、光照非均匀性、16-bin 亮度直方图）描述每张图；
3. 训域探针（balanced logistic regression，5-fold CV）得到基线可分性；
4. 施加**标定驱动的确定性退化管线**：逐通道直方图匹配（目标 CDF 取检测车域中位数）→ 灰度化 → 高斯模糊 → 加性噪声。模糊 sigma 与噪声 sigma 在 60 张标定子集上做 9×8 网格联合搜索，最小化 4 个结构特征的相对误差；
5. 重算特征、重训探针，比较可分性；
6. 加做**同域对半分对照**，验证探针本身有效。

脚本：`scripts/probe_domain_align_20260829.py`、`scripts/probe_control_20260829.py`
产物：`output/domain_align_probe_20260829/`（`result.json`、`per_feature.csv`、`samples/`）

**这就是那个陷阱：每一个特征的分布中位数都对齐到 97% 以上，但两域的联合分布仍然可以被一个线性分类器以 99.5% 的精度分开。**

## 4. 为什么会这样

### 4.1 匹配中位数 ≠ 匹配点云

线性分类器不关心中位数，它关心两个点云是否被一个超平面分开。逐特征的直方图匹配把车间点云的**中心**搬到了目标域的中心，但没有改变它的**形状、协方差和相关结构**。两个点云仍然不相交，只是距离变近了一点。

### 4.2 确定性退化本身就是一种指纹

我对每一张图施加了**同样**的高斯模糊（各向同性、空间平稳）和**同样**的加性高斯噪声（i.i.d.）。而真实检测车图像的退化是：随车速变化的方向性运动模糊、随局部亮度变化的泊松-高斯噪声、特定质量的压缩伪影、随位置变化的照度衰减。

结果：**退化后的图"退化得太规整了"**，反而成为一种新的可识别签名。这解释了为什么结构特征的可分性不降反升（0.8650 → 0.9975）。

### 4.3 fft_high_ratio 的反向失败是典型例子

检测车图像的高频来自**稀疏的强线条**（线缆、金属细边），而我用**宽带像素噪声**去凑这个比例。总能量比能凑近，频谱结构完全不同——噪声是各向同性均匀的，线条是各向异性稀疏的。加了噪声反而让高频比从 0.3412 超调到 0.4052（目标 0.3597），越过目标 100%。

要把这一项做对，需要真实的相机 PSF、噪声模型和运动模糊标定——项目没有这些参数。

### 4.4 内容差异一个像素都没被碰

16-bin 直方图能匹配到 99.5%，是因为直方图**与空间无关**。但车间图是"一个螺栓的特写"，检测车图是"一段隧道的局部场景"。画面里**有什么东西**，风格迁移一个字都改不了。

## 6. 真正致命的不是风格，是先验错位

这才是离线手段在原理上够不着的地方。

### 6.1 一个此前没被量化的事实

统计 `data/train_data_2` 全部 7781 张训练图：

| 每图 GT 数 | 车间训练集 | 真实线路（770 张） |
|---:|---:|---:|
| 0（无缺陷） | 105 张（**1.3%**） | 199 张（**25.8%**） |
| 1 | 7476 张（**96.1%**） | 392 张（50.9%） |
| 2 | 180 张（2.3%） | 125 张（16.2%） |
| 3 | 20 张（0.3%） | 44 张（5.7%） |
| 4 | 0 | 10 张（1.3%） |

**训练集里 96.1% 的图片"恰好一个缺陷框"，无缺陷图只占 1.3%；真实线路上无缺陷图占 25.8%——相差 19 倍。**

每一张车间图都是一个缺陷部件的孤立特写，画面里出现的部件几乎必然是被标注为缺陷的那个。模型学到的先验是：

> **P(画面里的这个部件 = 缺陷) ≈ 98.7%**

而真实线路上，绝缘子、地线线夹、汇流排接头**到处都是，且绝大多数是正常的**。

### 6.2 这直接对应了 2840 个误报的来源

DG-v1 在 770 张上的误报按类别：

| 类别 | 真实线路 GT | 预测数 |
|---|---:|---:|
| INSD（绝缘子破损） | 216 | 742 |
| GWCNL（地线线夹螺母松动） | **0** | **614** |
| BSBM（汇流排接头螺栓缺失） | **0** | **459** |
| CBHPM | 204 | 206 |
| DRPS | 69 | 145 |
| **三类合计（INSD+GWCNL+BSBM）** | | **1815，占全部误报 63.9%** |

注意 **GWCNL 和 BSBM 在真实线路上 GT=0，却报出 614 和 459 个**。这两类部件（地线线夹、汇流排中间接头）在隧道里**无处不在，只是全都正常**。训练集里它们有 782 和 486 个样本，且**全是缺陷样本，没有一个是正常样本**。

于是模型的行为完全符合它的训练先验：看到线夹 → 报 GWCNL；看到汇流排接头 → 报 BSBM。

**风格迁移改的是 P(像素)，改不了 P(缺陷 | 部件出现)。** 这是条件概率的错位，不是分布形状的错位。把车间图调暗、调灰、调模糊，画面里依然没有"正常的线夹"。

| 方案 | 外部 Recall | 每图 FP | 依据 |
|---|---:|---:|---|
| 现状（stage4 / DG-v1） | 0.00% / 0.12% | 2.69 / 3.69 | 已测 |
| **纯离线风格对齐（认真做）** | **0.5% – 3%** | 不确定，可能升 | 外推：DG-v1 已做在线版（灰度 0.6 / gamma / 亮度 / 噪声 / 模糊 / 方裁），TP 0→1、FP +37%；离线版唯一增量是更精确的直方图匹配与不可微变换，而实测域可分性只降 0.5 pp |
| 离线风格对齐 + 真实线路硬负样本 | 5% – 15% | 可望降到 2 以下 | 负样本补上 P(缺陷\|部件) 的错位，风格对齐做辅助 |
| **混合域训练（车间 + 真实线路监督）** | **30% – 60%** | 1 – 3 | 直接给目标域监督信号；118 个 RHT 目标、199 张无缺陷图、814 个 GT 全部可用 |

**一句话：纯离线风格对齐的预期收益是"从 0.12% 到个位数的百分之几"，而改变数据构成的预期收益是"到 30%–60%"。两者不在一个量级。**

## 8. 结论与建议

### 8.1 值不值得做

| 判断 | 结论 |
|---|---|
| 技术上可行吗 | **可行**。逐特征弥合率中位数 97%，一阶统计量可以精确对齐 |
| 能消除域可分性吗 | **不能**。1.0000 → 0.9950，且这是 36 维低阶特征下的乐观估计；用 CNN 特征只会更可分 |
| 能提升召回吗 | **几乎不能**。DG-v1 的在线版本已证伪，离线版本仅多出更精确的一阶匹配 |
| 能降误报吗 | **不确定，可能反向**。DG-v1 的 FP 涨了 37% |
| 有副作用吗 | **有**。为对齐 laplacian_var 施加的模糊（1280 tile 尺度约 sigma≈1.2 px）会软化开口销缺口、螺母间隙这类 5–15 px 的细微特征；动态范围压缩到 luma_p95=73 会进一步压低缺陷对比度。8.14 已证明 elastic + shadow 就能让 CBHPM 召回从约 0.9 崩到 0.347 |
| 值得单独投入吗 | **不值得** |

### 8.2 它正确的位置：辅助，不是替代

**场景 A（推荐）**：当训练集里已经有 300–700 张真实线路图时，用风格对齐把车间数据"推向"检测车域，放大这少量真实数据的效果。这属于"少量目标域监督 + 风格迁移"，效果远好于纯 DG。

**场景 B（推荐）**：作为数据增强的一个**并列分支**——保留原图版本 + 增加一个拟真版本一起训练，**不要替换**。这样即使拟真版有害，原图分支也能保底。

**场景 C（不推荐）**：指望它替代混合域训练。实测已证明走不通。

**场景 D（明确反对）**：用 GAN / diffusion 做生成式翻译。它能在联合分布上做得比确定性管线好，但会直接改写缺陷区域——8.14 已经证明温和的 elastic 形变就能让 CBHPM 召回崩掉 65%，生成式模型的破坏性高一个量级，且无法验证。

### 8.3 如果仍要做，必须设止损线

成本很低（纯 CPU 图像管线，约 2.5 人天，不占 GPU），所以可以做一次，但必须按下面的流程：

1. **标定而不是猜测**。从 770 张真实图里估计：亮度 CDF、噪声模型（在平坦区估）、PSF（边缘剖面或相机光学参数）、FFT 径向功率谱。不要用手调的 gamma/亮度参数。
2. **生成并列版本**，不替换原图。
3. **门槛一（数据层）**：用本报告的探针流程重测域可分性。**若 balanced accuracy > 0.95，不要指望检测指标有实质提升**——本次实测的最优结果是 0.9950。
4. **门槛二（缺陷保真）**：退化后抽 50 张含框的图，让标注员盲评"缺陷是否仍可辨认"。**若超过 10% 判为不可辨认，立即放弃。**
5. **门槛三（效果层）**：用 1/4 数据、15 epoch 跑一版，在 LOSO-CV 上看外部 Recall。**若提升 < 5 个百分点，停止这条线，把预算转去补采真实线路数据。**

### 8.4 优先级重申

```
P0  混合域训练（真实线路监督进训练）        ← 能带来数量级变化
P0  协议对齐（车间图按 1280 滑窗切片）      ← 纯几何，无风险
P0  硬负样本（199 张无缺陷真实线路图）      ← 直接治 P(缺陷|部件) 错位
────────────────────────────────────────
P1  离线风格对齐（作为 P0 的辅助分支）      ← 有止损线，锦上添花
P2  GAN/扩散式生成翻译                     ← 明确反对
```

## 9. 本次实测的局限

如实列出，便于复核：

1. **样本**：源域 300 张、目标域 400 张（对照实验 150/200）。趋势稳健，但精确数值会随抽样浮动。
2. **特征**：36 维手工低阶特征，不是 CNN 特征。**CNN 的判别力更强，因此 0.9950 是乐观下界**，真实可分性更可能仍在 1.0 附近。
3. **管线族**：只测了"直方图匹配 + 灰度 + 高斯模糊 + 加性噪声"这一族确定性变换。生成式方法（GAN/扩散）在联合分布上可能更好，但带来缺陷破坏风险，需另做评估。
4. **只测了图像级特征，没测框级特征**。特别是"目标 vs 局部背景对比度"（训练域 33.71 → 真实域 3.50）这一项，直方图匹配是否会自动把它压到真实域水平、还是会造成"整体对齐但局部对比度仍偏高"，本次未测。**这是若要推进风格对齐，下一个必须先测的量。**
5. **没有做训练验证**。所有关于召回的预期都是外推，不是实测。
