# 接触网缺陷图片现场拍摄质量控制规范

> **适用场景**: 车间限定环境下的缺陷样本采集
> **配套文件**: 《接触网缺陷识别图片拍摄需求.xlsx》、`docs/模型输出与缺陷类型对照表.md`
> **版本**: 1.0 | 2026-07-27

---

## 1. 图像基本参数

### 1.1 分辨率与像素量

| 参数 | 要求 | 说明 |
|------|------|------|
| 最低分辨率 | **50MP（8192×6144 或等效）** | 部署图像为 127MP，训练切片为 1024×1024；50MP 可保证缺陷区域在切片中有足够像素 |
| 推荐分辨率 | 100MP+ | 如设备支持，优先使用最高分辨率 |
| 缺陷最小像素尺寸 | 短边 **≥ 200 px** | 螺母/销钉/螺栓在原始图像中的最小边不低于 200 像素 |
| 缺陷最大像素占比 | 主体占画面 **25%~70%** | 过小则细节不足，过大则缺少上下文 |

> **设备受限时（仅 20MP）**：必须缩短拍摄距离，确保缺陷短边 ≥ 150 px，并在记录表中注明"低分辨率补偿拍摄"。此类图片在数据集中占比不超过 30%。

### 1.2 画面比例

| 参数 | 要求 |
|------|------|
| 宽高比 | **4:3**（与部署图像 13000×9800 一致） |
| 禁止 | 16:9、1:1、全景拼接 |
| 方向 | **横向（landscape）** 为主；构件为垂直走向时可用纵向，但须在记录表中注明 |

### 1.3 图像格式与存储

| 参数 | 要求 |
|------|------|
| 文件格式 | **JPEG（质量 ≥ 95）** + RAW（如设备支持） |
| 色彩空间 | **sRGB** |
| 位深 | 8-bit（JPEG）/ 12-bit+（RAW） |
| 白平衡 | **手动固定 5500K（日光）**，禁止自动白平衡 |
| HDR | **关闭** |
| 机内降噪 | **关闭**（保留真实噪声纹理，与部署图像一致） |
| 机内锐化 | 关闭或设为最低 |
| 闪光灯 | 禁止机顶直闪；仅允许外接柔光/环形灯（见第 4 节） |
| 文件命名 | `{类别编码}_{缺陷情况}_{角度}_{光照}_{序号}.jpg` |
| 命名示例 | `GWCNM_clear_front_std_001.jpg`、`SVHBNL_3mm_side_dark_012.jpg` |

### 1.4 编码对照（命名用）

| 类别编码 | 中文名称 |
|---------|---------|
| `VHBNM` | 垂直悬吊安装底座螺母缺失 |
| `VHBNL` | 垂直悬吊安装底座螺母松动 |
| `SVHBNM` | 单支垂直悬吊槽钢底座螺母缺失 |
| `SVHBNL` | 单支垂直悬吊槽钢底座螺母松动 |
| `SVHTNL` | 单支垂直悬吊槽钢上方螺母松动 |
| `RHTBNM` | 刚性悬挂吊柱顶板底面螺母缺失 |
| `RHTBNL` | 刚性悬挂吊柱顶板底面螺母松动 |
| `GWCSBNM` | 地线线夹托板安装底座螺母缺失 |
| `GWCSBNL` | 地线线夹托板安装底座螺母松动 |

## 2. 拍摄几何控制

### 2.1 拍摄距离

| 缺陷类型 | 推荐距离 | 备选距离 | 说明 |
|---------|---------|---------|------|
| 螺母缺失/松动 | 0.5 ~ 1.0 m | 1.5 m | 螺母直径小，需近距离保证像素量 |
| 销钉缺失 | 0.5 ~ 1.0 m | 1.5 m | 同上 |
| 绝缘子破损 | 1.0 ~ 2.0 m | 0.5 m | 绝缘子体积较大 |
| 吊弦不受力 | 1.5 ~ 3.0 m | 1.0 m | 需要观察整体松弛形态 |
| 汇流排螺栓缺失 | 0.8 ~ 1.5 m | 2.0 m | 中等尺寸目标 |

### 2.2 拍摄角度

| 角度代号 | 定义 | 适用缺陷 |
|---------|------|---------|
| `front` | 正视，相机光轴垂直于构件安装面（0°±10°） | 全部类别 |
| `side` | 侧视，相机光轴与安装面成 45°~75° | 松动类（观察间隙）、缺失类（观察孔洞深度） |

- 每个缺陷实例至少覆盖 `front` + `side` 各一组
- 松动类以 `side` 为主（侧面更容易看到松动间隙）
- 缺失类 `front` 和 `side` 等量

### 2.3 方向约束

- **保持相机水平**，图像中"天在上、地在下"
- 禁止倒拍（训练禁止垂直翻转 `flipud=0.0`）
- 仰拍角度不超过 30°，俯拍角度不超过 30°
- 构件在画面中应保持与真实安装一致的朝向

## 3. 对焦与清晰度

### 3.1 对焦要求

| 参数 | 要求 |
|------|------|
| 对焦方式 | **手动对焦**或单点自动对焦（对焦点落在缺陷区域） |
| 光圈 | f/5.6 ~ f/8（保证景深覆盖构件前后 ±5 cm） |
| 验证 | 每张拍完后 **100% 放大检查缺陷区域**，确认合焦 |
| 废片标准 | 缺陷区域模糊、失焦 → 立即重拍，不进入数据集 |

### 3.2 快门速度

| 拍摄方式 | 最低快门速度 |
|---------|------------|
| 三脚架 | 1/60 s |
| 手持 | 1/125 s |
| 计划内运动模糊样本 | 1/15 ~ 1/30 s（每类限 20~30 张，标记 `blur`） |

### 3.3 ISO 控制

| 光照条件 | ISO 范围 | 说明 |
|---------|---------|------|
| 标准照明 | 100 ~ 400 | 噪点极低 |
| 暗光 | 800 ~ 3200 | 允许可见噪点，但缺陷区域必须可辨识 |
| 反光 | 100 ~ 400 | 反光本身已增加亮度，ISO 不宜过高 |

- 暗光样本的核心原则：**宁可稍暗，不可过噪**。ISO 超过 3200 时噪点纹理会干扰模型对小目标边缘的学习。

## 4. 光照条件控制与制作

### 4.1 三类光照场景定义

| 光照代号 | 定义 | 对应部署场景 | 对应增强函数 |
|---------|------|------------|------------|
| `std` | 标准照明：均匀、无强烈明暗对比 | 隧道内正常灯具照明 | 基础增强 |
| `dark` | 暗光：整体亮度低，仅局部有光源 | 隧道深处/灯具故障区段 | `tunnelize`, `night_augment` |
| `glare` | 反光：金属表面出现镜面高光白斑 | 灯具直射金属构件 | `glare_augment` |

### 4.2 标准照明（`std`）构造

**设备**：2 盏 LED 面板灯（色温 5500K）+ 柔光布

**布置**：
```
        [LED灯A + 柔光布]          [LED灯B + 柔光布]
              45°↓                      ↓45°
                    ┌──────────┐
                    │  构件    │
                    └──────────┘
                         ↑
                      [相机]
```

- 两灯对称放置于构件两侧，与构件成 45° 角
- 柔光布距灯 20~30 cm，消除硬阴影
- 目标：构件表面照度均匀，无强烈高光点，阴影柔和
- 验证：画面中最亮与最暗区域亮度比 ≤ 4:1

### 4.3 暗光（`dark`）构造

**设备**：1 盏 LED 手电筒（或单灯）+ 黑色遮光布

**布置**：
```
     [黑色遮光布围合，减少环境光]

              [单灯，低功率]
                   ↓ (远距离或加 ND 滤镜)
                    ┌──────────┐
                    │  构件    │
                    └──────────┘
                         ↑
                      [相机]
```

- **方法 A（推荐）**：关闭车间主照明，仅用一盏低功率 LED 从单侧照射，模拟隧道内单一灯具
- **方法 B**：保持车间照明，在相机镜头前加 ND8/ND16 减光镜压暗整体曝光
- **方法 C**：用黑色遮光布围合构件区域，仅留一个小口透光，制造"隧道深处"效果
- ISO 调至 800~3200，快门 1/60s（三脚架）
- 目标：画面整体偏暗，缺陷区域勉强可辨，有明显明暗过渡
- 验证：缺陷区域灰度值在 40~120（8-bit）范围内；完全不可辨识的废片重拍

### 4.4 反光（`glare`）构造

**设备**：1 盏裸 LED 手电筒（去掉柔光罩）+ 可选 CPL 偏振镜

**布置**：
```
     [裸光手电筒]
          ↘ 30°~60°
            ┌──────────┐
            │ 金属构件  │ ← 镜面反射
            └──────────┘
                 ↗ 反射光路
              [相机]
```

**物理构造步骤**：

1. **基础反光**：单个裸 LED 手电筒从 30°~60° 角照射金属构件，相机位于反射光路方向
2. **增强反光**：在螺母/销钉表面薄涂机油或喷水膜，增加镜面反射率
3. **多点反光**：两个手电筒从不同方向照射，产生 2~3 个高光斑
4. **裸金属**：用砂纸打磨测试构件局部，去除氧化层/涂层，露出高反射率裸金属
5. **CPL 控制**：镜头装 CPL 偏振镜，旋转至反光最强位置拍摄一组，旋转 90° 至反光最弱拍摄一组——一次布光获得"强反光→弱反光"梯度

**CPL 梯度拍摄工作流**（推荐，一次布光出三档）：

```
步骤 1: 固定手电筒位置和相机位置（三脚架锁死）
步骤 2: 装上 CPL 偏振镜
步骤 3: 缓慢旋转 CPL，从取景器中观察反光变化
步骤 4: 找到反光最强位置 → 拍摄一组（标记 glare_strong）
步骤 5: 旋转 CPL 约 45° → 拍摄一组（标记 glare_mid）
步骤 6: 旋转 CPL 至反光最弱位置 → 拍摄一组（标记 glare_weak）
步骤 7: 不改变 CPL，微调手电筒角度 ±15° → 补拍一组（改变高光斑位置）
```

> 此方法的优势：同一缺陷实例、同一构图，仅反光强度不同，可直接用于训练模型对反光梯度的鲁棒性。

**反光强度分级标准**（质检时参照）：

| 等级 | 代号 | 判定标准 | 是否可用 |
|------|------|---------|:---:|
| 弱反光 | `glare_weak` | 高光斑面积 < 缺陷区域 10%，缺陷形态完全可辨 | ✅ |
| 中反光 | `glare_mid` | 高光斑覆盖缺陷区域 10%~50%，缺陷形态仍可辨识 | ✅ |
| 强反光 | `glare_strong` | 高光斑覆盖缺陷区域 50%~80%，缺陷边缘可辨但中心被遮 | ✅（少量） |
| 过曝废片 | — | 高光斑完全吞没缺陷区域，或画面 > 30% 面积纯白 | ❌ 废片 |

- 每个类别的 `glare` 样本中，弱:中:强 建议比例 **3:5:2**
- `glare_strong` 样本每类不超过总量的 20%，过多会让模型学到"看不清=有缺陷"的捷径

**质量红线**：
- ✅ 高光白斑**部分覆盖**缺陷区域（遮挡 10%~80%），缺陷仍可辨识
- ❌ 高光白斑**完全吞没**缺陷区域（看不出缺陷形态）→ 废片
- ❌ 画面中超过 30% 面积过曝（纯白）→ 废片

### 4.5 补充光照场景（可选，每类 20~30 张）

| 代号 | 构造方法 | 目的 |
|------|---------|------|
| `side_light` | 单灯从正侧面 90° 照射，制造强烈明暗分界线 | 模拟隧道壁单侧灯具 |
| `blur` | 三脚架 + 1/15~1/30s + 拍摄时轻敲三脚架 | 模拟车辆振动模糊 |
| `wet` | 构件表面喷水 + 标准照明 | 模拟隧道渗水/潮湿 |

### 4.6 后期合成反光（辅助手段）

项目已内置 `glare_augment` 离线增强函数（`subway_defect/augmentations/scene.py`）：

```
功能：叠加 1~4 个镜面高光斑 + 方向性光条纹
概率：p=0.5
```

**合成 vs. 实拍效果对比**：

| 维度 | 物理实拍 | 后期合成（`glare_augment`） | 对训练的影响 |
|------|---------|--------------------------|------------|
| 高光斑形态 | 有镜头特定的星芒、多边形光斑 | 圆形/椭圆形高斯斑 | 低——模型只需学会"有亮斑干扰时仍识别缺陷" |
| 色散（紫边/绿边） | 高光边缘有真实色散 | 无 | 低——色散区域仅几个像素宽 |
| 传感器 blooming | 过曝区域向周围像素溢出，形成光晕拖尾 | 无，高光斑边缘锐利 | **中**——真实 blooming 会模糊缺陷边缘，合成无法模拟 |
| 局部对比度压缩 | 强光区周围对比度降低（镜头眩光） | 无，背景对比度不变 | **中**——影响模型对低对比度缺陷的学习 |
| 与场景的几何一致性 | 高光位置符合反射定律 | 随机叠加，可能出现在不合理位置 | 低——模型不依赖高光位置做判断 |
| 噪声交互 | 高光区噪声被压制，暗区噪声保留 | 均匀叠加，不改变底层噪声 | 低 |

**结论**：后期合成对训练**够用但不够真**。它可以教会模型"忽略亮斑干扰"，但无法教会模型"在 blooming 导致边缘模糊时仍定位缺陷"。因此：

**使用规则**：
- 后期合成仅作为**数据增强的补充**，不替代物理反光拍摄
- 反光类样本中，**≥ 50% 必须为物理实拍**（覆盖真实的 blooming 和对比度压缩）
- 合成增强由训练管道自动执行，无需手动处理
- 如果物理反光样本不足（如某类缺陷的构件表面不易产生反光），可将合成比例提高至 70%，但须在记录表中注明

## 5. 背景控制（车间环境专项）

### 5.1 核心原则

防止背景过拟合的关键不是"需要 600 种不同背景"，而是**让背景无法成为缺陷标签的预测特征**。模型走捷径的条件是"某种背景只出现在正样本中"，只要打破这个相关性，600 张来自同一车间的图片完全可用。

训练阶段 Mosaic（0.5\~0.8）+ CopyPaste（0.3\~0.6）增强会将背景切碎重组，进一步打乱背景-标签对应关系。因此拍摄阶段只需提供 **8\~10 种物理背景变化 + 50% 浅景深样本** 即可满足需求。

### 5.2 背景板轮换（最直接有效）

准备 **8\~10 块**不同材质/纹理的背景板（约 60×60 cm），拍摄时每 5\~8 张换一块：

| # | 材料 | 模拟的隧道背景 | 获取方式 |
|---|------|-------------|---------|
| 1 | 混凝土板（带模板纹路） | 隧道壁 | 建材市场切割 |
| 2 | 灰色水泥板（光滑） | 隧道壁（抹灰段） | 同上 |
| 3 | 锈蚀钢板 | 钢构件/支架 | 废铁市场 |
| 4 | 镀锌铁皮（带压型纹路） | 设备箱外壳 | 五金店 |
| 5 | 黑色橡胶垫 | 隧道内防水层 | 五金店 |
| 6 | PVC 管 + 线槽组合板 | 管线/桥架 | 水电材料店，将 3\~4 根 PVC 管和一段金属线槽固定在木板上 |
| 7 | 红砖/加气块 | 隧道壁（老旧段） | 建材市场 |
| 8 | 深色迷彩布/灰色土工布 | 不规则暗背景 | 五金/户外店 |
| 9 | 带电缆的木板（缠绕 2\~3 段真实电缆） | 隧道内电缆 | 车间现有材料 |
| 10 | 铝箔/不锈钢板（制造反光背景） | 金属构件密集区 | 五金店 |

> 成本约 200\~400 元，一次制作可反复使用。关键是**纹理和颜色差异要大**，不需要精确模拟隧道。

**操作要点**：
- 背景板放在构件后方 **20\~40 cm**，不要紧贴（紧贴会产生清晰阴影，成为新的固定特征）
- 背景板可以**倾斜 10°\~30°** 放置，避免与画面平行产生均匀纹理
- 每块背景板拍完后**旋转 90°/180°** 再拍一组，同一块板产生 2\~3 种纹理方向

### 5.3 景深控制：让背景"消失"

**最省力且最有效**的方法——背景模糊后，模型无法从中提取任何纹理特征：

| 参数 | 设置 | 效果 |
|------|------|------|
| 光圈 | **f/2.8 ~ f/4** | 景深极浅，构件后方 10 cm 即开始虚化 |
| 拍摄距离 | 0.5 ~ 0.8 m（近距离） | 进一步压缩景深 |
| 焦距 | 85 mm 以上（长焦） | 背景压缩 + 虚化增强 |
| 构件与背景距离 | ≥ 30 cm | 确保背景完全失焦 |

- 每类 600 张中建议 **40%\~50%（约 250\~300 张）使用浅景深**，背景完全虚化为色块
- 剩余 50%\~60% 使用 f/5.6\~f/8（正常景深），配合背景板轮换
- 浅景深样本的额外好处：迫使模型只关注构件本身的局部纹理，与部署时 1024 切片中"构件占主体"的特征分布一致

### 5.4 构件位置/姿态变化

在同一车间内，改变构件的**安装位置和方式**：

| 方法 | 操作 | 效果 |
|------|------|------|
| 换工位 | 在车间的 3\~4 个不同工位/墙面/柱子前拍摄 | 背景结构（墙面颜色、设备、管线）不同 |
| 换夹具 | 台钳夹持 / 铁丝悬挂 / 木架支撑 / 平放桌面 | 构件周围的支撑结构不同 |
| 换高度 | 构件放在地面 / 桌面 / 高架（1.5m）上拍摄 | 背景从地面变为墙面/天花板 |
| 微调朝向 | 构件水平旋转 0° / 45° / 90° / 135° | 背景在画面中的位置改变 |

> 注意：构件本身的安装朝向不要倒置（`flipud=0.0`），但可以水平旋转。

### 5.5 前景/边缘干扰物

在画面**边缘**（不是缺陷区域）放置不同的干扰物，增加背景复杂度：

- 一段电缆从画面角落穿过
- 一把扳手/螺丝刀放在构件旁边（不遮挡缺陷）
- 一块抹布搭在构件边缘
- 不同颜色的手套放在背景中

这些干扰物在每张图中不同，防止模型将"干净的车间台面"学为特征。

### 5.6 自然光变化（如有窗户）

如果车间有窗户，利用不同时段拍摄：

| 时段 | 光线特征 | 标记 |
|------|---------|------|
| 上午（侧光） | 窗户方向强侧光，另一侧暗 | `std_am` |
| 正午（顶光） | 均匀明亮 | `std` |
| 傍晚（暖光） | 色温偏暖，阴影拉长 | `std_pm` |
| 阴天 | 柔和散射光 | `std_overcast` |

不需要刻意安排，正常拍摄周期内自然覆盖即可。

### 5.7 背景多样性量化标准

| 条件 | 最低背景多样性 | 说明 |
|------|:---:|------|
| 有 Mosaic + CopyPaste 增强（当前配置） | **5\~8 种**背景板 + 浅景深 | 增强会进一步打乱，5 种物理背景足够 |
| 仅基础增强（翻转/缩放） | **15\~20 种**背景变化 | 需要更多物理多样性补偿 |
| 无任何增强（不推荐） | **50+ 种** | 几乎不可能在车间实现，必须加增强 |

### 5.8 600 张/类的推荐拍摄分配示例

以"地线线夹托板安装底座螺母缺失（GWCSBNM）无遮挡 480 张"为例：

| 维度 | 分配 | 张数 |
|------|------|:---:|
| **景深** | 浅景深 f/2.8\~4（背景虚化） | 200 |
| | 正常景深 f/5.6\~8（背景板轮换） | 280 |
| **背景板**（正常景深部分） | 10 块板 × 每块约 28 张 | 280 |
| **角度** | front 240 + side 240 | 480 |
| **距离** | 0.5m / 1.0m / 1.5m 各 160 | 480 |
| **构件实例** | 至少 3 个不同构件，每个贡献 ~160 张 | — |
| **工位** | 车间 3 个不同位置轮换 | — |

> 浅景深 200 张不需要背景板（背景已虚化），正常景深 280 张配合 10 块背景板，每块板在 3 个工位各拍 ~9 张，自然覆盖。

### 5.9 背景禁区

- ❌ 纯白墙壁（与隧道差异过大，且模型可能学到"白底=缺陷"）
- ❌ 有明显文字/标识/工具的背景（引入无关特征）
- ❌ 其他型号/非接触网的金属构件出现在画面中（混淆类别特征）

## 6. 负样本（正常样本）采集与域不匹配应对

### 6.1 问题背景

当前数据存在**正负样本来源不一致**的风险：

| 数据 | 拍摄来源 | 背景特征 |
|------|---------|---------|
| 正样本（缺陷） | 车间 | 车间墙壁、工作台、检修架 |
| 已有负样本（正常） | 实际运行场景 | 隧道壁、管线、设备箱 |

如果模型学到 **"车间背景 → 有缺陷，隧道背景 → 正常"** 的伪相关（spurious correlation），则在真实隧道部署时会将所有隧道背景的图像判为"正常"，导致**漏检**。

### 6.2 影响程度判断：中等偏低

此风险**存在但可控**，原因如下：

1. **切片以构件为主体**：训练使用 1024×1024 切片，切片中心 70%+ 面积是螺栓/螺母/销钉等金属构件，背景仅在边缘。同型号构件在车间和隧道中**外观一致**，模型主要学习的是构件局部纹理而非背景。
2. **两阶段架构天然缓解**：Stage 1（ROI 提案器）只判断"此处有接触网结构"，Stage 2（缺陷检测）只看局部缺陷形态。负样本主要影响 Stage 2 的分类决策，而 Stage 2 的感受野集中在构件区域。
3. **域适应阶段兜底**：项目训练管道包含 Stage 2 域适应（`stage2_domain_adapt.yaml`），专门用于弥合训练-部署的域差距。
4. **场景增强模糊差异**：`tunnelize`、`night_augment` 等增强会改变图像的整体色调和亮度分布，使车间和隧道背景在增强后的特征空间中趋近。

**但仍需补救**——如果不做任何处理，在极端情况下（车间背景非常单一且与隧道差异极大），模型仍可能走捷径。

### 6.3 补救措施（按优先级排序）

#### 🔴 措施一：车间补拍负样本（最重要，拍摄阶段执行）

| 参数 | 要求 |
|------|------|
| 数量 | 每类缺陷对应 **100~200 张**，16 类共 1600~3200 张 |
| 内容 | 同型号构件的**正常/完好状态**（螺母紧固、销钉在位、绝缘子完好） |
| 背景 | **与正样本相同的车间背景**（消除背景伪相关） |
| 角度/光照 | 与正样本相同的角度和光照组合（std / dark / glare 均覆盖） |
| 命名 | `NORMAL_{构件类型}_{角度}_{光照}_{序号}.jpg` |

**核心原则**：正样本和负样本的背景分布必须重叠。模型看到"同一背景下既有缺陷又有正常"，才会被迫学习缺陷本身的形态特征。

**拍摄要点**：
- 在同一构件上，拍完缺陷区域后，**将相机移至正常部位**拍 2~3 张
- 正常部位应包含与缺陷部位**同类型的紧固件**（如：拍了螺母缺失后，在旁边紧固的螺母处拍正常样本）
- 确保正常样本中**确实无缺陷**——松动 1mm 以下的不要当作"正常"
- 每换一个背景板拍正样本时，**同步用该背景板拍负样本**

#### 🟡 措施二：训练时混合批次（训练阶段执行）

不要将车间数据和隧道数据分成不重叠的批次。每个训练 batch 中应同时包含：

| 组合 | 来源 | 作用 |
|------|------|------|
| 车间背景 + 有缺陷 | 本次拍摄 | 学习缺陷形态 |
| 车间背景 + 无缺陷 | 本次拍摄（措施一） | 打破"车间=缺陷"伪相关 |
| 隧道背景 + 无缺陷 | 已有数据 | 学习真实场景的正常外观 |
| 隧道背景 + 有缺陷 | 历史数据（如有） | 学习真实场景的缺陷外观 |

> 项目 `validate_dataset.py` 会检查 source-group 泄漏（同一拍摄来源不得同时出现在 train 和 val 中），混合时注意按**构件实例**而非按**背景来源**划分 train/val。

#### 🟡 措施三：增强对齐（训练阶段执行）

对车间正样本和隧道负样本施加**相同的场景增强**，使两者的光照/色调分布趋近：

- 车间正样本：施加 `tunnelize`（暗化 + 暖色聚光灯），模拟隧道光照
- 隧道负样本：施加 `white_balance_shift`（色温偏移），拉近与车间照明的色调
- 两者均施加 `glare_augment`，统一反光干扰分布

项目的离线增强脚本（`scripts/generate_scene_augmentations.py`）已支持按类别均衡增强，无需额外开发。

#### 🟢 措施四：已有隧道负样本保留使用

- 已有的实际运行场景负样本**不要丢弃**，作为域外泛化数据保留
- 训练时与车间负样本混合，比例建议：**车间负样本 60% + 隧道负样本 40%**
- 如果隧道负样本数量不足，不强制补充——车间负样本是核心
- 隧道负样本的额外价值：让模型见到真实隧道的管线、设备箱、渗水痕迹等车间无法模拟的背景元素，提升部署时的泛化能力

### 6.4 验证方法

训练完成后，通过以下方式检验域不匹配是否已被有效缓解：

| 检验项 | 方法 | 通过标准 |
|--------|------|---------|
| 背景伪相关 | 用**隧道背景 + 车间构件（正常）** 的测试图推理 | 不应报出缺陷（置信度 < 0.3） |
| 背景伪相关 | 用**车间背景 + 隧道构件（有缺陷）** 的测试图推理 | 应正确检出（置信度 > 0.5） |
| 整体指标 | 在隧道实拍测试集上评估 Recall / Precision | Recall ≥ 90%, Precision ≥ 90% |

> 如果前两项检验出现明显的背景依赖（如车间背景正常图被误报），说明负样本域不匹配仍未解决，需追加车间负样本或调整训练混合比例。

## 7. 逐张质检清单

每张图片拍完后，按以下清单逐项检查。**任一项不通过即标记为废片，不进入数据集。**

| # | 检查项 | 通过标准 | 常见废片原因 |
|---|--------|---------|------------|
| 1 | 对焦 | 缺陷区域 100% 放大后纹理清晰 | 自动对焦跑到背景上 |
| 2 | 曝光 | 缺陷区域灰度 30~240，无大面积死黑/死白 | 金属反光过曝 |
| 3 | 反光遮挡 | 高光白斑未完全覆盖缺陷区域 | 闪光灯/手电筒角度不当 |
| 4 | 缺陷占比 | 主体占画面 25%~70% | 太远（<10%）或太近（>80%） |
| 5 | 缺陷可辨 | 不看标签也能判断缺陷类型和程度 | 模糊/遮挡/角度过偏 |
| 6 | 方向 | 图像中"天在上、地在下"，无倒置 | 仰拍过度/相机旋转 |
| 7 | 遮挡 | 无手指、工具、电线等遮挡缺陷区域 | 手持构件拍摄 |
| 8 | 白平衡 | 金属件呈正常银灰色，无明显偏蓝/偏黄 | 自动白平衡漂移 |
| 9 | 画面完整 | 无黑边、无拼接痕迹、无镜头污渍 | 镜头脏/遮光罩遮挡 |
| 10 | 文件命名 | 符合 `{编码}_{情况}_{角度}_{光照}_{序号}` 格式 | 漏标/错标 |
