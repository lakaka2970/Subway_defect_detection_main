# 1 — 前端开发方案

> 涵盖：车载分析软件前端 + 地面分析软件前端（Vue3 + TypeScript）

---

## 1. 技术栈

> 与实际工程 `inspection-system-web` 对齐：**npm workspaces（Monorepo）+ Electron**（非 pnpm/Tauri）。

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue | 3.5+ | Composition API + `<script setup>` |
| TypeScript | 5.7+ | 类型安全 |
| Vite | 6.x | 构建与开发 |
| Element Plus | 2.9+ | UI 组件库（表格/表单/弹窗等） |
| Pinia | 2.3+ | 状态管理 |
| Vue Router | 4.5+ | 路由 |
| Axios | 1.7+ | HTTP 请求（含 Mock 开关 `VITE_USE_MOCK`） |
| **OpenSeadragon** | 4.x | 超高分辨率图像瓦片浏览 |
| **fabric.js** | 6.x | 图像标注（矩形/多边形缺陷框绘制） |
| **ECharts** | 5.x | 统计图表 |
| **Dexie.js** | 4.x | IndexedDB 封装，离线缓存 |
| **Electron** | 34.x | 车载端桌面壳；electron-builder 打包便携版 EXE |

> 备选图像库：附件 SRS 提及 Viewer.js / Cropper.js / splitpanes-vue，可用于轻量查看与分屏；本方案主用 OpenSeadragon（瓦片）+ fabric.js（标注）以支撑 1.27 亿像素场景，分屏用 CSS Grid/splitpanes 均可。

### 1.1 为何选 OpenSeadragon 而非直接加载原图

1.27 亿像素原图在浏览器中全量加载会导致内存溢出。OpenSeadragon 支持 **DZI (Deep Zoom Image)** 瓦片协议，按需请求当前视口区域的瓦片：

```
前端 → GET /api/v1/image/{imageId}/tiles/{level}/{col}/{row}.jpg
后端/Nginx → 静态瓦片文件 或 动态生成瓦片
```

**备选方案**：若 DL 团队不生成瓦片，后端实时切片。车载端小规模可用 `img` 标签加载压缩版（2560px 宽），仅双屏复核时走瓦片。

### 2.1 设计原则

- **共享最大化**：`packages/shared/` 放所有可复用的 API 层、组件、store、工具函数
- **端侧差异化最小化**：车载和地面只在不同功能点（如双屏复核）上独立实现
- **组件与后端解耦**：所有组件通过 Pinia store 获取数据，store 内部调用 API，组件不直接依赖 Axios

## 4. 核心组件设计

### 4.1 图像分析工作台 — 地面端核心

这是整个前端最复杂的组件，用于双屏对比复核：

```
┌──────────────────────────────────────────────┐
│  工具栏: [缩放] [旋转] [亮度] [锐化] [截图] [标注]  │
├──────────────────────┬───────────────────────┤
│    左屏：原始图像      │   右屏：AI 识别结果      │
│   (OpenSeadragon)    │  (OpenSeadragon)      │
│                      │  + fabric.js 标注叠加   │
│                      │                       │
│  可拖动/缩放/旋转      │  缺陷框高亮 + 置信度标签   │
├──────────────────────┴───────────────────────┤
│  缩略图导航条：支柱图像序列（可左右滑动切换）         │
├──────────────────────────────────────────────┤
│  缺陷列表面板：类型 | 置信度 | 位置 | 状态 | 操作   │
│  [确认] [待观察] [驳回] [新增标注] [删除]         │
└──────────────────────────────────────────────┘
```

**技术实现要点**：
- OpenSeadragon 双实例，通过 `addHandler('viewport-change')` 同步左右视口
- fabric.js Canvas 覆盖在右侧 OpenSeadragon 上面，坐标转换公式：
  ```
  图像坐标(x,y) = (画布坐标(x,y) - 图像偏移) / 缩放倍数
  ```
- 缺陷框数据从后端加载后，在 fabric.js 上绘制矩形/多边形，点击触发缺陷列表联动

## 5. 与后端接口对接规范

### 5.1 Axios 实例

```typescript
// packages/shared/src/api/index.ts （与实际代码一致）
import axios from 'axios';

const USE_MOCK = import.meta.env.VITE_USE_MOCK !== 'false';

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || '/api/v1',
  timeout: 30000,          // 默认 30s，AI 接口可能更长
  headers: { 'Content-Type': 'application/json' }
});

// 请求拦截：附加 Token
http.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// 响应拦截：成功码校验 + 解包 data + 统一错误处理
http.interceptors.response.use(
  res => {
    const body = res.data;            // { code, data, message, requestId }
    if (!isSuccessCode(body.code)) {
      handleApiError(body.code, body.message);
      return Promise.reject(body);
    }
    return body.data;                 // 直接返回业务数据
  },
  err => {
    handleApiError(err.response?.data?.code, err.response?.data?.message);
    return Promise.reject(err);
  }
);

// request() 统一入口：支持 Mock 降级（联调前用本地 Mock 推进前端）
export async function request<T>(method, url, data?, mockFn?): Promise<T> {
  if (USE_MOCK && mockFn) return (await mockFn()).data;
  // ... 真实请求
}
```

> **联调约定**：前端通过 `VITE_USE_MOCK` 开关在「本地 Mock」与「真实后端」间切换；接口路径、字段、错误码以《4-接口规范标准》为准。

### 5.2 接口模块示例

```typescript
// packages/shared/api/modules/aiTask.ts
export const aiTaskApi = {
  start: (taskId: string) =>
    http.post<{ analysisId: string }>(`/api/v1/aiTask/start`, { taskId }),

  control: (analysisId: string, controlType: 'pause' | 'resume' | 'cancel') =>
```

## 6. WebSocket 连接管理

**用途**：AI 分析进度实时推送、缺陷状态变更通知。

```typescript
// packages/shared/composables/useWebSocket.ts
export function useWebSocket() {
  const ws = ref<WebSocket | null>(null);
  const connected = ref(false);
  const progress = ref<AnalysisProgress | null>(null);

  function connect(taskId: string) {
    const token = localStorage.getItem('access_token');
    const url = `${import.meta.env.VITE_WS_URL}/api/v1/ws/analysis/${taskId}?token=${token}`;
    ws.value = new WebSocket(url);

    ws.value.onmessage = (event) => {
      const data = JSON.parse(event.data);
      if (data.type === 'progress') {
        progress.value = data.payload;
      }
    };

    ws.value.onclose = () => {
      connected.value = false;
      // 断线提示 + 自动重连（指数退避，最多 5 次）
      reconnect();
    };
  }

  return { connect, progress, connected };
}
```

**断线降级**：WebSocket 断开后，自动切换到 HTTP 轮询（每 5s 调用 `GET /api/v1/aiTask/progress/{taskId}`），WebSocket 恢复后切回。

## 7. 离线与弱网方案（车载端）

### 7.1 缓存策略

| 数据类型 | 缓存位置 | 容量限制 | 过期策略 |
|----------|----------|----------|----------|
| 任务列表摘要 | IndexedDB | 200 条 | 7 天 |
| 最近访问缩略图 | IndexedDB | 500 张 | LRU |
| 用户 Token | LocalStorage | — | 跟随服务端过期 |
| 分析进度 | Pinia（内存） | — | Tab 关闭清空 |

### 7.2 网络检测

```typescript
// 使用 Navigator.onLine + 心跳检测
function useNetworkStatus() {
  const online = ref(navigator.onLine);
  // 每 30s 发一个 HEAD 请求到后端 health 端点验证真实连通性
  return { online };
}
```

断网时：
- 界面顶部显示黄色横幅："当前网络不可用，数据将在恢复后同步"
- 禁止发起新 AI 分析（显示灰色按钮）
- 已缓存的数据（缩略图、任务列表）仍可浏览

## 9. 关键性能优化

| 场景 | 策略 |
|------|------|
| 1.27 亿像素图像加载 | OpenSeadragon 瓦片协议，视口内按需加载 |
| 大量缩略图 | 虚拟滚动 + 懒加载 + WebP 格式 |
| 缺陷列表（可能 10 万条） | 后端分页（默认 50 条/页）+ 虚拟滚动 |
| 重复打开同张图 | IndexedDB 缓存瓦片 |
| 报表导出（Excel/Word/PDF） | 后端异步生成 + 前端显示下载进度；Word 报表含缺陷信息与标注图（缺陷治理建议书） |
| ECharts 大数据渲染 | 数据聚合到合理粒度（如按天/周聚合）再渲染 |

## 10. 构建与部署

### 10.1 车载端（Electron 便携版）

```bash
# 构建 Vue3 前端 + 修正资源路径 + electron-builder 打包便携版 EXE
npm run build:onboard:exe        # 等价 vite build --base ./ && fix-dist-html && electron-builder --win portable
```

Electron 配置要点（`packages/onboard/electron/main.cjs`）：
- 主进程通过 Node 能力访问本地文件系统
- 打开本地文件夹：`shell.openPath(absolutePath)` / `shell.showItemInFolder()`
- 本地后端健康检测：启动时检查车载单体后端 `localhost:8080/actuator/health`
- 产物：`release/福州地铁车载分析软件-{version}-便携版.exe`（appId `com.fuzhou.metro.inspection.onboard`）

### 10.2 地面端

```bash
# 构建纯 Web 前端 → 部署到 Nginx（B/S）
npm run build:ground
# 如需桌面端，也可 npm run build:ground:exe 生成便携版
```

Nginx 配置要点：
- 前端静态文件 + 后端 API 代理（`/api/*` → Spring Boot）
- 图像瓦片直接通过 Nginx 静态服务或代理到 MinIO
- CORS 配置：生产环境使用 Origin 白名单
